# R5決算 統合版

`R5決算_統合.xlsx` は、元の8ファイル（①〜⑧）を外部リンクなしの1ブック（117シート）にまとめたものです。

## 構成
- 先頭に 目次 / 整合チェック / ハードコード一覧 / 改修ログ を追加（既存セルは変更なし）
- そのあとに ①〜⑧ のシートを順に配置（「総括表」の重複だけ、⑥側を「総括表(不課税)」に改名）
- 元の数式・書式・コメント・図形・印刷設定はそのまま

## 目次・整合チェックの見方
- 目次 C4 が総合判定。「変化あり」→ 検算セルが元の値と変わった／「エラー値が増加」→ エラーセルが基準より増えた
- 整合チェック: 既存の検算セル29か所（「↓エラーあり」の27か所と、最終チェックの過不足額2か所）を一覧化
  - 8か所は元のExcelの時点で既に「↓エラーあり」でした（`雨汚水(共通按分後)` と `確認用` の M2, W2, AL2, M53 相当）。元のまま残しています。要確認です
- ハードコード一覧: 数式に直接書かれた数値107件（手入力調整値52、定数55）

## マクロ（VBA）
`VBA/modR5Tools.bas`（Shift-JIS）を、Excel で次の手順で取り込みます。
1. 統合ブックを開き、`名前を付けて保存` で「Excel マクロ有効ブック (.xlsm)」として保存
2. Alt+F11 → ファイル → ファイルのインポート → `modR5Tools.bas`
3. Alt+F8 → `R5_Menu` を実行

主な機能: 数値スナップショットの保存と比較（`R5_SaveSnapshot` → 修正 → `R5_CompareSnapshot` で差分を一覧）、エラー値・直書き数値の走査、外部リンク確認、シート一覧、全シートPDF出力。
**VBAはこの環境にExcelがなく、実行していません。** 初回は小さなコピーで試してください。
