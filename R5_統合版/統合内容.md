# R5決算 統合版

8つのExcelを1つのブック（113シート）にまとめ、ファイル間の外部リンクをすべて同一ブック内のシート参照に置き換えました。

- シートの並び順：①3条支出 → ②3条収入 → ③4条支出 → ④4条収入 → ⑤雨汚水 → ⑥不課税収入の区分 → ⑦消費税 → ⑧一般会計繰入金決算
- シート名の重複は「総括表」のみ（⑥と⑧）。⑥側を「総括表(不課税)」に改名し、参照式も付け替え済み
- 数式は元と同じ（外部リンク部分だけ内部参照に変更）。書式・列幅・結合セル・コメント・図形・印刷設定は元のまま
- 外部リンクは0件。開くときのリンク更新警告は出ません
- 前回の修正（年度別調書の#DIV/0!解消、⑧の不要な名前定義の削除）も反映済み
- 開いたとき全再計算する設定です
- 元の8ファイル（R5_改良版）は、このブックの代わりに使う場合のみ必要です。2つを混在させないでください

## 確認したこと
- 元の全セル(約37万)の数式が、外部リンク部分を除いて一致
- 書式・結合セル・列幅・行高・コメント数が一致
- LibreOffice で開いて再計算できる
- 差が出る値（約3,200セル）は、LibreOffice と Excel の SUMIFS の仕様差が主な原因と見ています（先頭の0付き文字列キーの照合など）。Excel で開いて、合計表（総括表・消費税・繰入金）が元の値と合うか確認してください。
  なお、元ファイル自体が外部リンクの更新前の値を保持していた可能性もあり、その場合は統合後に数値が最新データへ更新されます
