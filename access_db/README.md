# 検出事項データベース（Access版）構築セット

## 含まれるファイル
| ファイル | 内容 |
|---|---|
| `KensyutsuDB.bas` | テーブル・クエリ・フォームを一括作成する VBA（文字コード Shift-JIS：Access の取り込み仕様に合わせています） |
| `m_problem.tsv` | 問題点マスタ 1,949件（問題点入力表(xls)の「項目1／項目(2)／項目③／区分／問題点／内容説明」を抽出。UTF-8） |

## 構築手順（約5分）
1. 空の Access データベース（.accdb）を新規作成し、`m_problem.tsv` と**同じフォルダ**に保存する。
2. Alt+F11 で VBA エディタを開く → ファイル → ファイルのインポート → `KensyutsuDB.bas`。
3. ツール → 参照設定で「Microsoft Office xx.0 Access database engine Object Library」（DAO）が有効であることを確認する（通常は既定で有効）。
4. （起動時に「v3」と表示されない場合は古い版です。取り込み直してください）
5. イミディエイトウィンドウ（Ctrl+G）に `Setup` と入力して Enter。
   （フォームでエラーが出て中断した場合は、テーブルは作成済みなので `SetupForms` だけを実行する。仮名の「フォーム1」が残っていたら保存せず削除する）
5. 完了メッセージの後、いったん閉じて開き直すと `F_メニュー` が起動する。

## 作成されるもの
- テーブル：`T_検出事項`（1件1行）／`M_問題点`／`M_区分`／`M_グループ`／`M_対応状況`（リレーションあり）
- クエリ：`Q_検出事項一覧`（結合ビュー）／`Q_問題点入力表`（問題点×グループのクロス集計）
- フォーム：`F_検出入力`（項目1→(2)→(3)で絞り込んで問題点を選択）／`F_メニュー`
- メニューから：新規入力、一覧表示、キーワード検索、復命用一覧の Excel 出力、問題点入力表の Excel 出力

## 複数人での同時編集
構築後、Access の「データベースツール → Access データベース」（分割）でテーブルをバックエンド化し、
バックエンドを共有フォルダに置き、各PCにフロントエンドを配布する。

## 注意（要確認事項）
- この環境には Access が無いため、**実機で動作確認していません**。エラー時はエラー番号と行を教えてください。修正します。
- `M_グループ`・`M_対応状況` の初期値はサンプルの記載から推定したものです。年度ごとに実態に合わせて編集してください。
- 「問題点入力表」出力は、検出のあった問題点のみの行が出ます（件数0の行は出ません）。0件行も含めた全項目表が必要なら追加対応します。
- 実在の受託者名・金額等を含む場合のアクセス権限は、庁内の情報セキュリティの規定に従って別途検討してください。
