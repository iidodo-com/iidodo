# 検出事項 入力フォーム(Excel VBA UserForm)

## 注意(先に読んでください)
- UserForm は VBA(マクロ)なので、ブックを **`.xlsm`**(マクロ有効ブック)で保存する必要があります。
- **Excel のブラウザ版(Teams 内で開く画面)ではマクロは動きません。** 入力は「デスクトップ版 Excel で開く」必要があります。
- 共同編集との相性は未確認です。複数人が同時に「登録」すると、同じ行へ書き込む競合が起こりうるため、同時に使うときは注意してください(担当グループごとにファイルまたは行を分ける運用が安全です)。
- この環境には Excel がなく、**実機で動作確認していません**。エラーが出たら、メッセージと黄色くなった行を教えてください。

## 設置手順
1. `検出事項データベース.xlsx` を開き、「名前を付けて保存」で **Excel マクロ有効ブック(.xlsm)** にする。
2. Alt+F11 で VBA エディタを開く。
3. メニュー「挿入」→「ユーザーフォーム」。作られた UserForm1 を選び、プロパティウィンドウ(F4)で **(オブジェクト名) を `frmInput`** に変更する。
4. そのフォームを右クリック→「コードの表示」(または F7)。表示されたコード欄の内容を全部消し、`frmInput_code.txt` の中身をすべて貼り付ける。
5. 「ファイル」→「ファイルのインポート」で `KensyutsuInput.bas` を取り込む。
6. VBA エディタを閉じ、Excel で Alt+F8 → `OpenInputForm` を実行する(任意で `SetShortcut` を1回実行すると Ctrl+Shift+I で開けます)。

## 使い方
- 年度・局課名・グループ・担当者は、登録後も残ります(続けて入力できます)。
- 項目1 →(2)→(3)→区分→問題点の順にプルダウンで選ぶと、候補が絞り込まれます。項目(3)が無い事務は、(2)の次に区分を選びます。
- 問題点で「（その他）内容欄に記載」を選んだ場合は、内容(要約)の入力が必須です。
- 登録・クリア・閉じるボタンは、画面上部(紺色の帯)にあります。縦に長い場合は右端のスクロールバーで下へ送れます。
- 候補が出ないときは、画面上部の水色の文字に「候補がありません」と出ます。その文字と、選んだ項目名を教えてください。
- 「登録」で「入力」シートの次の空き行に書き込みます。件数・通番・集計用の列は、シートの数式がそのまま働きます。
- 入力欄は 2,001 行目までです。

## 既知の制約
- 登録済みの行の修正はフォームではできません(「入力」シートで直接修正してください)。
- 「入力」シートの並べ替えや行の挿入をしたあとは、次の空き行が正しく選ばれない場合があります(問題点の列の最終行の次へ書き込みます)。
