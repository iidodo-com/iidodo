# 検出事項データベース(Access版 v2) 第1段階: テーブルとマスタ

## 方針
Access を試して、難しければ Excel + SharePoint に切り替える。第1段階は、データの入れ物(テーブル)とマスタだけ。画面(フォーム)は第2段階。

## 含まれるファイル
| ファイル | 内容 |
|---|---|
| `Step1Tables.bas` | テーブル・マスタ・クエリを作る VBA(Shift-JIS) |
| `m_problem.tsv` | 問題点マスタ 2,035 件(UTF-8)。Excel版と同じ内容 |

## 手順
1. **空の新しい .accdb** を作る(ファイル形式は Access 2007〜2016 でよい)。
2. `m_problem.tsv` を、その .accdb と**同じフォルダ**に置く。
3. Alt+F11 → ファイル → ファイルのインポート → `Step1Tables.bas`。
4. ツール → 参照設定で「Microsoft Office xx.0 Access database engine Object Library」が有効であることを確認(通常は有効)。
5. イミディエイトウィンドウ(Ctrl+G)に `Step1_Setup` と入力して Enter。
6. 完了メッセージの後、`Step1_Check` を実行して、件数を確認。

## 期待値(Step1_Check)
M_区分 5 / M_グループ 6 / M_対応状況 5 / M_備考区分 3 / M_問題点 2035 / T_検出事項 0

## 作られるもの
- テーブル: `T_検出事項`(1問題点=1件) / `M_問題点` / `M_区分` / `M_グループ` / `M_対応状況` / `M_備考区分`
- クエリ: `Q_検出事項一覧` / `Q_問題点入力表`(問題点×グループの件数)

## 注意
- この環境には Access が無いので、**実機で動作確認していません**。止まった場合は、メッセージ(「〇〇で止まりました」とエラー番号)を教えてください。
- 前回の Access 版(KensyutsuDB.bas)は使いません。新しい空のデータベースで始めてください。
