# 検出事項データベース(Access版 v2)

方針: Access を試して、難しければ Excel + SharePoint に切り替える。
構成: データ本体(Access)を共有フォルダに置き、各自のパソコンに画面(フロントエンド)を置く。出力は Excel の別紙様式。

## ファイル
| ファイル | 内容 |
|---|---|
| `Step1Tables.bas` / `m_problem.tsv` | 第1段階: テーブルとマスタ(問題点 2,035 件)を作る |
| `Step2Forms.bas` / `F_input_code.txt` | 第2段階: 入力フォームとメニューを作る |
| `Step3Link.bas` | 第3段階(Access側): 分割後のリンク先の確認・付け替え |
| `AccessRefresh.bas` | 第3段階(Excel側): AccessからExcelへ読み込む(別紙・集計を最新にする) |

## 第1段階(テーブル)
1. **空の新しい .accdb** を作り、`m_problem.tsv` を同じフォルダに置く。
2. Alt+F11 → ファイル → ファイルのインポート → `Step1Tables.bas`。
3. Ctrl+G で `Step1_Setup` を実行 → `Step1_Check` で件数確認
   (M_区分 5 / M_グループ 6 / M_対応状況 5 / M_備考区分 3 / M_問題点 2035 / T_検出事項 0)。

## 第2段階(入力フォーム)
1. `F_input_code.txt` を、同じフォルダに置く。
2. `Step2Forms.bas` をインポート。
3. Ctrl+G で `Step2_BuildForms` を実行。完了後、いったん閉じて開き直す → メニューが表示される。
4. 「検出事項を新規入力」で動作確認。
   - 項目1 → (2) → (3) → 区分 → 問題点の順に選ぶと、候補が絞り込まれる。
   - 「保存して次へ」で保存し、次の入力欄へ(年度・日付・局課・グループ・担当者は引き継ぐ)。
   - 「（その他）内容欄に記載」を選ぶと、内容の入力が必須。
   - 上部の「記録を探す」で、登録済みの記録へ移動(修正・削除もここから)。

## 第3段階(共有フォルダ化とExcel連携)
### A. データベースの分割(Access標準機能)
1. 第2段階まで動いた .accdb を、**バックアップ**してから開く。
2. 「データベースツール」→「Access データベース」(分割)を実行する。
3. バックエンド(データ本体)の保存先に、**共有フォルダ**(ファイルサーバー上。Teams・OneDrive の同期フォルダは避ける)を指定する。
   できあがる `~_be.accdb` がデータ本体、元のファイルが画面側(フロントエンド)になる。
4. フロントエンドを、各自のパソコン(ローカル)にコピーして使う。共有フォルダの場所は全員同じ UNC パス(`\\サーバー\...`)にする。
5. 場所が変わったら、`Step3Link.bas` をインポートして `Step3_Relink` を実行する(`Step3_ListLinks` で現在のリンク先を確認できる)。

### B. Excel への出力(別紙様式)
1. 別紙入りのExcelブック(.xlsm)に `AccessRefresh.bas` をインポートする。
2. `SetAccessPath` を実行して、バックエンドの .accdb を選ぶ(M_設定 の K2 に保存される)。
3. 復命用一覧の C2 に年度を入れ、`RefreshFromAccess` を実行する。
   → 「入力」シートが最新データに置き換わり、別紙(復命用)・復命用一覧・問題点入力表・区分別集計が更新される。
4. 別紙の行を整える `FitBesshiRows`(BesshiFit.bas)を実行する。
- Excel からは**読み取り専用**で接続する(書き込みの競合は起きない)。
- この運用では、Excel の「入力」シートに直接入力しない(更新で置き換わる)。

## 試験手順(3人で)
1. 1人目: 新規入力で3件登録 → 2人目・3人目の画面で「記録を探す」に出るか確認。
2. 3人が同時に別々の記録を入力して保存できるか確認。
3. Excel で `RefreshFromAccess` → 別紙に反映されるか確認。

## 運用上の注意
- バックエンドは定期的にバックアップする(共有フォルダのコピーで可)。
- 同時に開く人数が増えたり、動作が遅くなったら、Access の「データベースの最適化/修復」を実行する。
- 受託者名などを含む場合は、共有フォルダのアクセス権を必要な人に限る。

## 注意
- この環境には Access / Excel が無いので、**実機で動作確認していません**。止まったときは、メッセージ(「〇〇で止まりました」とエラー番号)を教えてください。
- フォームのコードは、別ファイル(F_input_code.txt)から読み込んで埋め込みます。
