## はじめに：フローを新しく作る

フローの「入れ物」を作ります。ボタンを押したときに動く、手動で実行するフローです。

1. Power Automate の左のメニューで「Create」を押します。

→ 編集画面が開き、一番上に「Manually trigger a flow」という箱が1つできます。ここから、箱を下へ足していきます。

## 手順（上から順に、箱を足していく）

> **すべての手順は、「Try」という名前のまとめる箱の中**に作ります（失敗したときに通知するため）。

### 手順 1：Try（エラー処理の対象をまとめるスコープ）

エラー処理のために、最初に「Try」という名前の**まとめる箱（スコープ）**を作ります。このあとの手順は、すべてこの箱の中に作ります。

**やること**

1. トリガーの直下の「＋」を押します。
2. 出てきた画面の検索欄に `Scope` と入力し、候補の中の「Scope」（組み込み）を選びます。
3. できた箱の右上の「…」→「Rename」を選び、名前を `Try` に変えます。

**くわしい情報（確認したい方向け）**

- 「Scope」の名前と「Rename」の操作は、画面で確認していません ［想定］
- Code view で確認するポイント：`"type": "Scope"`

### 手順 2：現在日時（日本時間）を作る（式で日本時間の日付を使うため自動で追加）

このあとの手順で、「日本時間の今日」を使う式を貼ります。そのために、先に「現在の日時（日本時間）」を入れておく箱を作ります。

**やること**

1. Try の中の「＋」を押します。
2. 出てきた画面の検索欄に `Compose` と入力し、候補の中の「Compose」（組み込み（データ操作））を選びます。
3. できた箱の右上の「…」→「Rename」を選び、名前を `Compose_JST` に変えます。
4. 「Inputs」の欄をクリックし、開いた窓の「式（fx）」の欄に、下の文字を貼って、「Add」を押します。

```text
convertTimeZone(utcNow(), 'UTC', 'Tokyo Standard Time')
```

※ 箱の名前は、必ず `Compose_JST` にしてください（あとの式が、この名前で呼び出します）。


**くわしい情報（確認したい方向け）**

- 式 E00：日本時間の現在日時（基準となる Compose_JST）（**実機検証済み**（2026-10-07 Power Automate 英語表示・既定環境。全ケースが期待どおり。詳細は VERIFIED_RESULTS.md））
- 日本時間にする理由：`utcNow()` は UTC（世界標準時）を返すため、必ず `convertTimeZone` で `Tokyo Standard Time` に変換します。
- Code view で確認するポイント：`"type": "Compose"`

## 失敗したときにメールで知らせる（エラー処理）

処理の途中で失敗したときに、担当者へメールが届くようにします。

しくみ：本処理を「Try」の箱に入れ、もう1つ「catch」という名前の箱を作ります。**catch は、Try が失敗したときだけ動いて、メールを送ります。**（正常に終わったときは、catch は動きません。）

### ① catch（まとめる箱）を作る

1. 「Try」の箱の**下**の「＋」を押します。
2. 検索欄に `Scope` と入力し、「Scope」を選びます。
3. できた箱の右上の「…」→「Rename」を選び、名前を `catch` に変えます。

### ② catch の中に、失敗を知らせるメールを作る

1. `catch` の箱の中の「＋」を押します。
2. 検索欄に `Send an email (V2)` と入力し、「Send an email (V2)」（Office 365 Outlook）を選びます。
3. 左のパネルで、次の欄に入力します（下の図と表のとおり）。


| 番号 | 画面の入力欄 | 入れる内容 |
| --- | --- | --- |
| 1 | To | a@example.com |
| 2 | Subject | 失敗 |
| 3 | Body | 失敗 |

### ③ catch を「Try が失敗したときだけ動く」設定にする（実行条件）

1. `catch` の箱をクリックし、左のパネルの「Settings」タブを開きます。
2. 「Run after」の下に、いま動かすきっかけになっている箱（直前の箱）が出ています。
3. 「＋ Select actions」を押し、一覧から **Try** にチェックを入れます。
4. Try の行で、「Is successful」の**チェックを外し**、「Has timed out」と「Has failed」に**チェック**を付けます（「Is skipped」は外したまま）。
5. 直前の箱（例：Apply to each など）の行が残っていたら、右端の**ゴミ箱**で削除します。残すと、その箱が成功し、かつ Try が失敗しないと動かない設定になり、catch が動かなくなります。
6. 保存します。


> 正常に終わったときは、catch の箱は灰色（実行されない）のままになります。

**くわしい情報（確認したい方向け）**

- Settings タブ、Run after、Select actions、Is successful／Has timed out／Is skipped／Has failed、ゴミ箱の表示は、実際の画面で確認しました ［画面で確認済み］
- 「Scope」の名前、「Rename」、「Add an action」の操作は、画面で確認していません ［想定］
- メールの入力欄の名前（To・Subject・Body）は、画面で確認していません ［想定］。JSON：`emailMessage/To`、`emailMessage/Subject`、`emailMessage/Body`（HTML で保存） ［サンプルで確認済み］
- Code view で確認するポイント（catch の箱）：`"type": "Scope"`、`"runAfter": { "Try": ["TimedOut", "Failed"] }` ［サンプルで確認済み］（`samples/actions/control__scope__run_after_failed.json`）

## 用語の説明

- **箱（アクション）**：フローの中の、1つ1つの処理です。画面では、四角い箱で表示されます。
- **トリガー**：フローが動き出す「きっかけ」です。一番上の箱です。
- **＋（プラス）**：箱を足すためのボタンです。箱と箱の間や、まとめる箱の中にあります。
- **スコープ（Scope）**：いくつかの箱を、まとめて入れる大きな箱です。この手順書では、「Try」と「catch」に使います。
- **式（fx）**：日付の計算などを行う「命令」です。この手順書に載っているものを、コピーして貼ります。
- **動的なコンテンツ（⚡）**：前の箱の結果を、入力欄に入れる機能です。
- **Run after（実行条件）**：前の箱が、どうなったとき（成功／失敗…）に、その箱を動かすかの設定です。
- **Code view**：箱の設定を、文字で見る画面です。作った内容を確認したい人向けです。
