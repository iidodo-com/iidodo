# メール受信による承認フロー

## 目的
申請のメールが届いたら、決まった承認者（課長など）に承認を依頼し、承認または却下の結果を申請者（メールの差出人）へメールで知らせる。

## 事前準備
- 承認者のメールアドレス（1人）を決めておく
- 申請を受け付けるメールの条件（件名に含める言葉など）を決めておく

## トリガー
- 種類: Outlook 新しいメールが届いたとき
- 件名フィルター: 【申請】
- フォルダー: 受信トレイ

## 手順

### 1. 承認を依頼して待つ
- 動作: 承認の作成と待機
- 承認の種類: 承認/拒否 - 最初に応答した人
- タイトル: 申請の承認依頼：{{メールの件名}}
- 割り当て先: 承認者のメールアドレス
- 詳細: 差出人と本文を表示する

### 2. 結果で分ける
- 動作: 条件
- 条件: 手順1の結果が「承認」かどうか

#### 2-1. 承認だったとき
- 動作: メール送信
- 宛先: {{メールの差出人}}
- 件名: 【承認】{{メールの件名}}
- 本文: 申請が承認されました。

#### 2-2. 却下だったとき
- 動作: メール送信
- 宛先: {{メールの差出人}}
- 件名: 【却下】{{メールの件名}}
- 本文: 申請が却下されました。

## エラー処理
- 通知先: 自分のメールアドレス
- 件名: 【失敗】承認フローでエラーが起きました
- 本文: 承認フローが途中で止まりました。実行履歴を確認してください。

## テスト

### テスト1: 承認
- 準備: 件名に【申請】を入れたメールを自分宛てに送る
- 操作: 承認者として「承認」を押す
- 期待結果: 差出人に【承認】のメールが届く

### テスト2: 却下
- 準備: テスト1と同じ
- 操作: 承認者として「却下」を押す
- 期待結果: 差出人に【却下】のメールが届く
