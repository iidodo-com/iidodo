式の検証マニュアル

Power Automate の画面で、私たちが作った「式」が正しく動くかを確かめる手順です。パソコン操作に慣れていなくても、上から順にやれば進められるように書いています。

この作業の目的
  • 日付を日本時間にするなどの「式」は、Microsoft の公式説明書を読んで書いたものです。まだ実際には動かしていません。
  • 間違った日付が本番のフローに出ないよう、小さなテスト用フローで答え合わせをします。
  • 所要時間の目安：最初の4グループ（全21ケース）で、慣れれば約40分です。1グループずつ、日を分けても構いません。
画面の名前について
この手順の画面名は、実際に表示された英語の画面（Power Automate の「Create」ページ）をもとに書いています。画面が更新されると言葉が変わることがあります。違う言葉が出たら、近いものを選ぶか、画面を撮って私に送ってください。

1. テスト用フローを作る（最初の1回だけ）

  1. 「Create」ページを開く
    左のメニューの Create を押します。
  2. 「Instant cloud flow」を押す
    上の段の左から2番目です。説明は「Triggered manually as needed.」（必要なときに手動で実行）です。
  3. 名前とトリガーを決める
    「Flow name」に 式の検証 と入力します。トリガーは Manually trigger a flow を選び、Create を押します。
  4. 「＋」を押して Compose を追加する
    上の箱の下にある ＋（Add an action）を押し、検索欄に Compose（日本語表示は「作成」）と入力して選びます。
  5. 「Inputs」欄をクリックする
    追加された箱の Inputs（入力）欄をクリックします。近くに小さな窓が出ます。
  6. 「fx」（Expression＝式）の欄を探す
    窓の中に fx または Expression と書かれたタブか欄があります。ここが式を貼る場所です。
    注意：「Copilot」と書かれた窓は使わないでください。
    「Create an expression with Copilot」は、AI に式を作ってもらう別の欄です。300文字までしか入らず、AI が式を書き換えてしまうことがあります。
    この窓が開いてしまったら、左上の 「＜」（戻る） か右上の 「×」 で閉じてください。「OK」は押さないでください。
  7. 式を貼り付ける
    下の「3. 検証ケース」の式の右の コピー ボタンを押し、式の欄に貼り付けます（Ctrl＋V）。先頭に @ は付けません。貼ったら Add（または OK）を押します。
  8. 箱の名前をケースIDにする
    箱の右上の … → Rename（名前の変更）で、E00_1 のようにケースIDにします。
    これが、結果を見比べるときの目印です。
  9. 箱を増やす
    手順4〜8を繰り返し、ケースの数だけ箱を並べます。まず「ステップ1」の3つだけ作れば十分です。
  10. 保存して実行する
    右上の Save（保存）→ Test（テスト）→ Manually（手動）→ Run flow（フローの実行）→ Done の順に押します。実行が終わったら、各箱をクリックして Outputs（出力）を見ます。

2. 結果の見方

見えたもの意味・やること
箱が緑（チェック）で、出力に値がある成功です。出力の値を期待する出力と見比べます。文字の出力は "2026/10/06" のように引用符 " が付いて見えますが、問題ありません。
値が期待と違う失敗ではありません。大事な情報です。表示された値をそのまま「実際の出力」に書いてください。
箱が赤い（エラー）赤い箱をクリックして、エラーの文章を全部コピーして「実際の出力」に書いてください。その箱は削除して、もう一度実行します。赤い箱があると、その後ろの箱は動きません。
式を貼ったら「正しくありません」と出たその文章をそのまま書いてください。

「観察」と付いたケースは、期待する出力が私の予想です。違っていてもそれが答えなので、正直に書いてください。

3. 検証ケース（コピー用）

各ケースの式の右の「コピー」を押すと、式がまるごとコピーされます。ページ内の「実際の出力」と「判定」に書き込むと、一番下でまとめて私に送れる文章が作れます。書いた内容はこのページを閉じると消えるので、途中で閉じるときは先に一番下の「結果をまとめる」を押してコピーしてください。

ステップ1：現在日時（まずここから）

日本時間への変換が動くかを確認します。最初の1つ（E00_1）は、すでに成功したとのことなので、結果の値だけ教えてください。

E00_1観察固定のUTC時刻を日本時間へ変換（時刻部分の確認）
期待する出力2026-10-07T00:30:00.0000000
メモ末尾に Z／オフセットが付くかどうかを確認
貼り付ける式（1行ぜんぶ）
convertTimeZone('2026-10-06T15:30:00Z', 'UTC', 'Tokyo Standard Time')
E00_2変換結果を日付時刻の書式にする
期待する出力2026/10/07 00:30
貼り付ける式（1行ぜんぶ）
formatDateTime(convertTimeZone('2026-10-06T15:30:00Z', 'UTC', 'Tokyo Standard Time'), 'yyyy/MM/dd HH:mm')
E00_3観察本番式の実行確認（現在時刻）
期待する出力実行した時刻の日本時間（目視で、手元の時計と一致すること）
メモ期待値は固定できないため目視確認
貼り付ける式（1行ぜんぶ）
convertTimeZone(utcNow(), 'UTC', 'Tokyo Standard Time')

ステップ3：全角スペースの除去

全角スペースが標準の機能で消えるか、公式説明書に書かれていないため確認します。結果は数字で出ます。

E10_1【前提確認】検証用の入力（全角スペース＋山田＋全角＋太郎＋全角＋半角）の文字数
期待する出力8
貼り付ける式（1行ぜんぶ）
length(concat(decodeUriComponent('%E3%80%80'),'山田',decodeUriComponent('%E3%80%80'),'太郎',decodeUriComponent('%E3%80%80'),' '))
E10_2観察【観察】標準の trim だけで両端の全角スペースが消えるか（文字数で確認）
期待する出力（5：全角・半角とも両端除去 / 7：半角だけ除去 / 8：何も除去されない。結果を知らせてください）
メモ最重要の観察ケース。結果に応じて式の根拠を確定する
貼り付ける式（1行ぜんぶ）
length(trim(concat(decodeUriComponent('%E3%80%80'),'山田',decodeUriComponent('%E3%80%80'),'太郎',decodeUriComponent('%E3%80%80'),' ')))
E10_3式A（両端の全角・半角スペースを除去。途中の全角は半角に統一）
期待する出力山田 太郎

E10_5式B（途中も含めてスペースをすべて除去）

貼り付ける式（1行ぜんぶ）

4. 結果を私に送る

上のケースに書き込んだら、下のボタンを押して、できた文章をコピーして貼り付けて送ってください。

書き込みが面倒なときは、画面のスクリーンショットでも構いません。

5. 困ったとき

「Create an expression with Copilot」という窓が開いた

AI に式を作ってもらう別の欄です。左上の「＜」か右上の「×」で閉じ、「OK」は押さずに、窓の中の fx（Expression）の欄を探してください。

式を貼ったあと、「OK」や「Add」が押せない

式の最初や最後に余分な文字（スペースや改行、@）が入っていないか確認してください。「コピー」ボタンを使うと余分な文字は入りません。

「fx」の欄が見つからない

「Inputs」欄をクリックした直後の画面を、窓全体が見える形で撮って送ってください。どれが式の欄かを案内します。

実行したら、後ろの箱が灰色のまま動かない

前の箱のどれかが赤くなっています。赤い箱の文章を記録して削除し、もう一度実行してください。

途中でやめたい／日を分けたい

フローは保存されているので、いつでも続きから再開できます。このページの入力内容だけは消えるので、先に「結果をまとめる」でコピーしてください。

6. このあとの予定

順番内容
いまこの4グループ（E00・E01・E10・E09）を実行して、結果を送る。
次残りの式（和暦・翌営業日・月末・ファイル名・Excel・空欄・件数・年度・日数差）を検証する。一覧は expressions\VERIFY.md にあります。
並行してアクションの「見本」（サンプルJSON）を用意する。手順は docs\sample_checklist.md にあります。
そのあと見本を読んで構造メモを作り、内容を確認していただいてから、手順書づくり・チェック機能に進みます。
