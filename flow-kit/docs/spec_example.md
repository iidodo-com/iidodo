# 申請一覧の取込と完了通知

## 目的
- OneDrive の「申請一覧」（Excel）の行を1件ずつ確認する。
- 処理が終わったら、担当者にメールで知らせる。
- 途中で失敗したときも、担当者にメールで知らせる。

## 事前準備
- OneDrive に「申請一覧.xlsx」を置き、表（テーブル）の名前を「申請テーブル」にしておく。
- 通知の宛先に使うメールアドレスを決めておく（練習のときは自分宛て）。

## トリガー
- 種類: 手動

## 手順
### 1. 処理件数を数える変数を用意する
- 動作: 変数の初期化
- 変数名: counter
- 種類: 整数
- 初期値: 0

### 2. 申請一覧を読み込む
- 動作: Excel表の行を一覧表示
- 場所: OneDrive for Business
- ドキュメントライブラリ: OneDrive
- ファイル: /申請/申請一覧.xlsx
- テーブル: 申請テーブル
- ページ分け: オン
- しきい値: 5000

### 3. 1件ずつ確認する
- 動作: それぞれに適用
- 繰り返す対象: 手順2の一覧

#### 3-1. 確認の記録を作る
- 動作: 作成
- 入力: 確認しました

### 4. 完了を通知する
- 動作: メール送信
- 宛先: tantou@example.com
- 件名: 【完了】{{式: 日本時間の今日の日付}} 申請一覧の確認
- 本文: 申請一覧の確認が完了しました。
- 重要度: Normal

## エラー処理
- 通知先: tantou@example.com
- 件名: 【失敗】申請一覧の確認で失敗しました
- 本文: フローの実行履歴を確認してください。

## テスト
### テスト1: 件数が少ない表で最後まで動く
- 準備: 申請テーブルに3行のテストデータを入れる（例: A001〜A003）
- 操作: フローを手動で実行する
- 期待結果: すべての箱が緑になり、完了通知のメールが1通届く

### テスト2: 表が見つからないときに失敗通知が届く
- 準備: 申請一覧.xlsx の名前を一時的に変える
- 操作: フローを手動で実行する
- 期待結果: Try が赤になり、catch が動いて失敗通知のメールが届く
