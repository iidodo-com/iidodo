# 新しいチャットに貼るプロンプト

新しいチャット（セッション）の最初に、次の文章をそのまま貼ってください。

```text
私は自治体の事務職員で、IT は素人です。説明は、専門用語を避けて、丁寧にお願いします。
これから、Power Automate のクラウドフローを、画面で自分で作ります。その作成を手伝ってください。

まず、GitHub の最新の main を取り込んでください（古いコピーのことがあります）。
  git fetch origin main
  git checkout -B main origin/main
そのあと、次の2つを読んでください。
  flow-kit/docs/HANDOFF.md
  flow-kit/CLAUDE.md
（flow-kit が見つからないときは、GitHub のツールで iidodo-com/iidodo の main ブランチから
 flow-kit/docs/HANDOFF.md を直接読んでください。それでも読めなければ、私に教えてください。）

読んだら、次のことをしてください。
1. いまの状態を、3行で要約する。
2. 私に、「作りたい業務」を聞く（何を・いつ・どこから・誰へ）。質問は少なく、選べる形でお願いします。
3. 私の答えから、業務手順書（flow-kit/docs/spec_format.md の書式）の下書きを作って、私に確認する。
4. 確認できたら、flow-kit/tools/build_guide.ps1 で構築手順書（HTML）を作って、私に渡す。
   （PowerShell 7 の入れ方は HANDOFF.md に書いてあります）
5. 私が画面で作りながら、スクリーンショットを貼ります。手順書と見比べて、間違いを教えてください。
6. 手順書にない動作（SharePoint、Teams、承認、Forms など）が必要なときは、
   私に Code view の取り出しをお願いして、サンプルを増やしてください。

大事なルール：
- サンプル（flow-kit/samples/）にない書き方は、推測で書かず「要確認（サンプルなし）」と書く。
- 私が貼ったデータは、保存する前に、ファイルID・フォルダー名・個人名・メールアドレスが残っていないか確認して、伏字にする。
- 作業は、コミットして GitHub（main）に push する。
```

## 補足
- 新しいチャットの環境で `flow-kit` が見つからないときは、`flow-kit/docs/HANDOFF.md` の中身を、そのチャットに貼り付けてください（このフォルダーの `HANDOFF.md`）。
- 画面のスクリーンショットは、新しいチャットには引き継がれません。続きの作業では、撮り直してください。
