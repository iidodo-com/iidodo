決算ウォッチ（試作）

アプリへ戻る

使い方

決算ウォッチは、決算を跨がず、通過を確認してから判断するという投資スタイルを支えるための記録・管理ツールです。売買の推奨や助言は行いません。

1. ウォッチ銘柄を登録する

「銘柄を追加」からコード・銘柄名・市場を入力します。サンプル銘柄以外は決算日が自動設定されず「予定未設定」になるため、「予定を追加」から決算日を手入力してください（手入力は自動取得より優先されます）。「ウォッチ銘柄」タブで編集・削除ができます。

2. 決算予定を見る

「リスト」は日付順、「カレンダー」は月表示です。設定した警戒日数以内に入った決算は「設定した警戒日数内」と強調されます。この日数はあなたが決めるルール用の目印で、売買の指示ではありません。

3. 決算通過後にチェックする

決算日を過ぎた銘柄は「通過済・要確認」になります。行（またはカレンダーの銘柄）をクリックし、次の3欄を記録します。

  • 実績：売上・利益の結果と、予想や前年との差
  • ガイダンス：業績予想の修正や今後の見通し
  • 株価反応：発表後の値動きと出来高、所感

各欄の「自己評価」は、あなた自身の整理用ラベルです。3欄を確認したら「通過確認済みにする」を付けます。

3.5 カレンダーへの書き出し（ICS）

「ICS出力」で、現在表示中の決算予定を .ics ファイル（終日イベント）として保存できます。Googleカレンダー等の「インポート」から取り込めます。ダミー由来の予定は件名に「【ダミー】」が付きます。

3.6 J-Quants API を使う

「設定」でデータ取得元を「J-Quants API V2」にし、ご自身のAPIキーを入力すると、日本株の決算発表予定日を取得します。取得に失敗した場合は理由が表示され、「ダミーデータに切り替える」ことができます。

3.7 取得に失敗したとき

画面上部に失敗理由・対処方法・「再試行」ボタンが表示されます。既存の予定とチェック記録は変更されません。一部の銘柄だけ失敗した場合、その銘柄は前回の表示を保持します。詳しい対処は README の「うまくいかないとき」をご覧ください。

4. データの扱い

  • 入力内容はお使いのブラウザの localStorage にのみ保存されます。サーバには送信されません。
  • 「バックアップ書出／読込」でJSONとして保存・復元できます（APIキーは書き出されません）。ブラウザのデータを消すと記録も消えるため、定期的な書出をおすすめします。
  • 初期表示のサンプルはダミーです。実在の決算発表日ではありません。「サンプルに戻す」で初期状態に戻せます。

5. 注意

決算日は変更される場合があります。必ず各社の公式IR情報で確認してください。詳しくは利用規約をご覧ください。
