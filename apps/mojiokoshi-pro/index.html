音声から議事録までを一括生成

音声ファイルを選ぶだけで「文字起こし全文／整文／要約／決定事項とToDo」を出力します。

  1. ① ファイルを選ぶ
  2. ② 音量を確認
  3. ③ 実行
  4. ④ 結果を確認・出力

① 音声ファイル

② 送信前の音量チェック

音声はこの端末内で解析しており、まだ外部へは送信していません。

    ③ オプションと実行

    聞き取れない箇所は推測で埋めず「【聞き取れませんでした】」と表示する設計です。ただしAIの出力は完全ではないため、重要な内容は必ず原音で確認してください。

    履歴

    この端末のブラウザ（localStorage）にのみ保存されています。

      設定

      Gemini APIキー

      キーはこのブラウザの localStorage にのみ保存され、Google の API 以外には送信されません。コードには埋め込まれていません。 共用PCでは保存しないでください。Google AI Studio で発行できます。

      ※ gemini-3.5-flash は提供状況は要確認です（Google公式モデル一覧で記載を確認できていません）。エラーになる場合は「カスタム」で別のモデルIDを試してください。

      データの削除

      履歴と設定（APIキー含む）をこのブラウザから完全に削除します。

      使い方

      はじめに（約1分）

      1. デモで全体を確認：APIキー未設定のまま「文字起こし」画面で「サンプルを試す」を押すと、モックデータで全フローを確認できます。
      2. APIキーを設定：「設定」でGemini APIキーを入力して保存します。キーはお使いのブラウザ内にだけ保存されます。「接続テスト」でキーとモデルを確認できます。
      3. 音声を選ぶ：送信前に波形と音量チェックが表示されます。小さすぎる・無音の場合は警告が出ます。14MBを超える音声は Files API 経由（アップロード→処理待ち→生成）で自動的に処理されます（上限200MB）。
      4. 実行：文字起こし全文／整文／要約／決定事項とToDoが生成されます。
      5. 確認・修正・出力：文字起こし・整文・要約・決定事項の本文の直接編集、話者名の変更、発言ごとの話者の付け替え、コピー、TXT/Markdown保存ができます。結果は「履歴」に自動保存されます。

      誤りを減らすコツ

      • 口元の近くで録音し、できるだけ静かな環境で。音割れしない音量に。
      • 「【聞き取れませんでした】」「要確認」の表示は、AIが推測せずに残した印です。原音で確認してください。
      • 人名・数字・日付など重要な情報は、必ず原音と照合してください。

      注意

      • これは試作版です。可用性・精度・セキュリティの保証はありません。
      • 音声は Google の Gemini API に送信されます。機密性の高い音声を扱う前にプライバシーポリシーを確認してください。

      1. 本アプリが保存する情報

      APIキー、設定、処理結果の履歴（文字起こし・要約など）は、お使いのブラウザの localStorage にのみ保存されます。本アプリの運営者のサーバーには送信・保存されません（本試作版には運営者側サーバーがありません）。

      2. 外部への送信

      「実行」を押すと、選択した音声データと指示文が、Google の Gemini API（generativelanguage.googleapis.com）へ直接送信されます。14MBを超える音声は Gemini の Files API で一時的にアップロードされ（元のファイル名は送信しません）、処理後に本アプリが削除を試みます（削除に失敗した場合の保持期間は Google の仕様に従います）。デモモードでは外部へ送信されません。音量チェックは端末内で行われ、送信されません。「接続テスト」はAPIキーとモデルIDのみをGoogleへ送信します。

      3. 送信先での取り扱い

      送信されたデータの取り扱い（保存・学習への利用の有無等）は、ご利用のAPIプランと Google の規約・ポリシーに従います。機密性の高い音声を処理する前に、必ず最新の規約をご確認ください。

      本試作版は、アクセス解析ツールや広告・Cookieを使用していません。

      「設定」画面の「すべて削除」、またはブラウザのサイトデータ削除により、保存情報を消去できます。
