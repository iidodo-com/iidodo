音声から議事録までを一括生成

音声ファイルを選ぶだけで「文字起こし全文／整文／要約／決定事項とToDo」を出力します。

はじめての方へ（3ステップ）

  1. まずデモで試す：下の「ファイル無しでサンプルを試す」→「文字起こしを実行」。APIキーは不要で、結果画面まで確認できます。
  2. 実際に使う：「設定」でAPIキーを入力して「接続テスト」→ 音声ファイルを選んで実行。
  3. 確認・修正・出力：結果の4つのタブを確認し、必要なら直接修正して、コピーまたはTXT/Markdownで保存します。

          1. 3ステップで始める

          1. まずデモで試す（APIキー不要）：「文字起こし」画面で「ファイル無しでサンプルを試す」→「文字起こしを実行」。架空の会議データで、結果画面までの流れを体験できます。
          2. 実際に使う：「設定」でGemini APIキーを入力して「保存」→「接続テスト」で成功を確認。「文字起こし」で音声ファイルを選び、送信前の音量チェックを確認して「文字起こしを実行」。
          3. 確認・修正・出力：結果の4タブ（文字起こし全文／整文／要約／決定事項とToDo）を確認し、誤りは直接直します。「コピー」または「TXT／Markdownでダウンロード」で保存。結果は「履歴」に自動保存されます。

          2. APIキーについて

          • Google AI Studio でGemini APIキーを発行します（料金や無料枠はGoogleの規約に従います）。
          • キーはこのブラウザの中にだけ保存されます。当アプリの運営者や第三者のサーバーには送られません（通信先はGoogleのみ）。
          • 共用パソコンでは、使い終わったら「設定」→「APIキーだけ削除」を押してください。
          • キーの漏えいが心配なときは、Google側でキーを無効化・再発行してください。

          3. 画面の見かた

          • 音量チェック：送信前に、波形・平均音量・無音の割合を表示します。「問題あり」の音声は、確認チェックを入れないと実行できません（聞き取れない箇所が多くなるため）。
          • 【聞き取れませんでした】／要確認：AIが推測せずに残した印です。原音を聞いて確認し、正しい内容に書き換えると「要確認」は解除されます。
          • 編集済：あなたが手で修正した発言の印です。
          • 話者：「話者ラベル」で名前を変更でき、各発言のプルダウンで話者を付け替えられます。担当者名にも反映されます。
          • 14MBを超える音声：自動的に「Files API」でアップロードされます（上限200MB）。時間がかかるため、進捗が表示されます。
          • デモモード：APIキー未設定、または設定で強制ONのとき。画面上部に表示され、実際の送信は一切行いません。

          4. 個人情報を守る（マスキング）

          名前や電話番号などを外部に送りたくない場合の機能が3つあります。それぞれ守れる範囲が違うので、違いを理解して使ってください。

          機能何をするか守れる範囲
          送信前マスキング
          （文字起こし画面）          		指定した時間区間の音声を無音化してから送信無音化した区間の内容はGoogleに送られません。指定した区間だけが対象です。
          用語ヒントの除外伏せ字辞書の語を含む行を、用語ヒントから除いて送信用語ヒント（テキスト）に辞書の語が混ざって送られるのを防ぎます。
          出力時の伏せ字
          （辞書）          		コピー／TXT／Markdown で、辞書の語を ■ に置換出力ファイルの共有時の漏えいを防ぎます。Googleへの送信後の処理であり、送信内容は伏せません。
          1. 設定の「伏せ字辞書」に、氏名・社名などを1行1語で登録（出力時の伏せ字用）。
          2. 文字起こし画面で音声を選び、プレーヤーで再生しながら、氏名などが話されている区間の「開始」「終了」を指定して「＋区間を追加」（「再生位置を入れる」で現在位置を入力できます）。
          3. 「マスク後の音声を試聴して確認」で、その区間が無音になっていることを必ず確認してから実行。
          4. 「送信内容の確認」を開くと、Googleに何が送られるかを実行前に確認できます。

          ⚠ 音声から氏名を自動で検出して伏せることは、文字起こし前にはできません。指定していない区間はそのまま送信されます。機密性の高い音声は、送信前に全体を確認してください。

          6. よくある質問

          音声データは保存されますか？

          当アプリは音声を保存しません（ブラウザ内で処理し、Googleへ送信するだけです）。履歴に残るのは、文字起こし結果とファイル名だけです。送信後のGoogle側の取り扱いは、ご利用のAPIプランとGoogleの規約に従います。

          結果はどこに保存されますか？

          お使いのブラウザの中（localStorage）だけです。ブラウザのデータを消去すると失われるため、大切な結果はTXT/Markdownで保存してください。端末間の同期はありません。

          AIの出力は信頼できますか？

          誤りを含む可能性があります。人名・数字・日付などの重要な情報は、必ず原音で確認してください。聞き取れなかった箇所は推測せず【聞き取れませんでした】と表示する設計ですが、誤りがゼロになる保証はありません。

          料金はかかりますか？

          当アプリ自体の料金プランはダミー表示です。Gemini APIの利用料金・無料枠は、お持ちのAPIキーとGoogleの規約に従います。

          スマホのホーム画面に追加できますか？

          対応ブラウザでは「ホーム画面に追加」または「アプリをインストール」から追加できます（PWA）。

          データを全部消したい

          「設定」→「すべて削除」で、履歴・設定・APIキー・辞書をこのブラウザから削除できます。

          1. 本アプリが保存する情報

          2. 外部への送信

          「実行」を押すと、選択した音声データと指示文が、Google の Gemini API（generativelanguage.googleapis.com）へ直接送信されます。14MBを超える音声は Gemini の Files API で一時的にアップロードされ（元のファイル名は送信しません）、処理後に本アプリが削除を試みます（削除に失敗した場合の保持期間は Google の仕様に従います）。デモモードでは外部へ送信されません。音量チェックは端末内で行われ、送信されません。「送信前マスキング」を使うと、指定した区間を無音化した音声（ブラウザ内で作成）が元のファイルの代わりに送信され、無音化した区間の内容は送信されません。ただし、指定されていない区間はそのまま送信されます。「伏せ字辞書」による ■ への置換は、送信後に行う出力時の処理であり、送信内容は変えません（用語ヒントから辞書の語を除外する場合を除く）。「接続テスト」はAPIキーとモデルIDのみをGoogleへ送信します。
