# 文字起こしアプリ商用版（試作）

音声ファイルから **文字起こし全文／整文／要約／決定事項とToDo** を一括生成する、ビルド不要の静的Webアプリです（Gemini API 利用）。
サーバー不要・GitHub Pages 互換（すべて相対パス）。APIキーは利用者のブラウザ内にだけ保存されます。

> ⚠ **リリース候補（試作）です。** 実際の Google サーバーとの疎通は未確認です（[検証状況](#10-検証状況正直な記録)）。利用規約・プライバシーポリシー・料金ページは**ダミー／ひな形**で、法務確認を受けていません。

## 1. 30秒で試す（デモ）

```bash
cd apps/mojiokoshi-pro
python3 -m http.server 8000     # → ブラウザで http://localhost:8000/ を開く
```

1. 「文字起こし」画面で **「ファイル無しでサンプルを試す（デモ）」** を押す
2. **「文字起こしを実行」** を押す（APIキーは不要。通信もしません）
3. 結果画面で、4つのタブ・話者の付け替え・直接編集・コピー・ダウンロード・履歴を確認できます

`file://` で直接開くと Service Worker（PWA）が動きません。HTTP(S) 経由で開いてください。
GitHub Pages では `https://<user>.github.io/<repo>/apps/mojiokoshi-pro/` で動作する想定です。

## 2. 実際に使う（初回セットアップ）

1. [Google AI Studio](https://aistudio.google.com/apikey) で Gemini APIキーを発行
2. アプリの「設定」でキーを入力 →「保存」
3. 「**接続テスト**」を押し、「✔ 成功」を確認（キーの有効性とモデルの存在を確認します。生成は行わないため課金対象の推論は発生しません）
4. 「文字起こし」で音声ファイルを選び、実行

- モデルは既定 `gemini-3.8-flash`、代替 `gemini-3.5-flash`（※提供状況は要確認）、または「カスタム」で任意のモデルIDを指定できます。
- キーがあってもデモにしたい場合は「デモモードを強制」にチェック。

## 3. 画面の使い方

| 画面 | できること |
|---|---|
| 文字起こし | 音声を選択 → 波形・音量チェック → （任意）送信前マスキング → 「送信内容の確認」→ 実行。14MB超は自動で Files API（上限200MB） |
| 結果 | 4タブの確認、**本文の直接編集**（全タブ）、話者名の変更・発言ごとの話者付け替え、ToDoの担当/期限/完了の編集、コピー、TXT/Markdownダウンロード（自動で履歴に保存） |
| 履歴 | 検索（ファイル名・話者・本文・要約・ToDo）、再表示、削除、全削除 |
| 設定 | APIキー、モデル、接続テスト、デモ強制、**伏せ字辞書**、データ全削除 |
| 使い方／料金／規約／プライバシー | ヘルプ（エラー対処表・FAQ付き）、ダミーの料金、ひな形の規約 |

**結果画面の見かた**
- `【聞き取れませんでした】` と **要確認**：AIが推測せずに残した印。原音で確認し、正しい内容に書き換えると「要確認」は解除されます。
- **編集済**：手で修正した発言の印。
- 音量チェックが「問題あり」の音声は、確認チェックを入れないと実行できません。

## 4. 個人情報を守る（マスキング）

守れる範囲が異なる3つの機能があります。**違いを理解して使ってください。**

| 機能 | 場所 | 何をするか | 守れる範囲 |
|---|---|---|---|
| **送信前マスキング** | 文字起こし画面 | 指定した時間区間の音声を**無音化**した音声（16kHzモノラルWAV）を作り、元ファイルの代わりに送信 | 無音化した区間の内容は **Google に送られません**（送信データ自体を伏せる） |
| **用語ヒントの除外** | 自動 | 伏せ字辞書の語を含む「用語ヒント」の行を、送信前に除外 | テキストとして送られる用語ヒントへの混入を防ぐ |
| **出力時の伏せ字** | 設定（辞書）／結果画面 | コピー／TXT／Markdown で辞書の語を ■ に置換 | 出力物の共有時の漏えい。**送信後の処理**で、送信内容は変えない |

**送信前マスキングの手順**
1. 音声を選ぶと「送信前マスキング」欄が出ます（30MB以下の音声）。
2. 上のプレーヤーで再生し、氏名などが話されている区間の「開始」「終了」を入力（`1:23`、`01:02:03`、`83` などの形式。「再生位置を入れる」で現在位置を入力可）→「＋区間を追加」。重なる区間は自動で結合されます。
3. **「マスク後の音声を試聴して確認」** で、その区間が無音になっていることを確認。
4. 「送信内容の確認」を開くと、Google に送られる音声・指示文・用語ヒントを実行前に確認できます。
5. 実行。結果には「送信前マスキング: n区間（計x秒）」が記録され、TXT/MD の見出しにも明記されます。

> ⚠ **限界**：文字起こしの前なので、音声から氏名を**自動で検出して伏せることはできません**。区間は利用者が指定します。**指定していない区間はそのまま送信されます。** 機密性の高い音声は、送信前に全体を確認してください。再エンコード（16kHzモノラル化）により音質は元ファイルより下がります。無音化しても元の時刻は変わらないため、結果のタイムスタンプは元の音声に対応します。

## 5. エラーと対処

すべてのエラーに「**次にやること**」が表示されます。主なものは次のとおりです（アプリ内「使い方」にも同じ表があります）。

| 表示 | 主な原因 | 次にやること |
|---|---|---|
| APIキーが無効です | 入力ミス・失効・余分な空白 | 設定でキーを入れ直し、「接続テスト」で確認 |
| キーに使えない文字が含まれています | 全角文字・空白・改行の混入 | Google AI Studio からコピーし直す |
| モデルが見つかりません（404） | モデルIDが存在しない・提供終了 | 設定の「カスタム」で別のモデルIDを入力、「接続テスト」で確認 |
| リクエスト上限に達しました（429） | レート/クォータ超過 | 1〜数分待って再実行。頻発するなら利用枠・課金を確認 |
| Google側で一時的なエラー（5xx） | サーバー混雑・障害 | **自動で最大2回再試行**（3秒・8秒後）。それでも失敗なら数分後に再実行 |
| タイムアウト | 長い音声・回線不安定（生成: inline 5分／Files 10分） | 音声を分割、回線の安定した環境で再実行 |
| Googleのサーバーに接続できません | 切断、VPN・プロキシ・拡張機能の遮断、CORS | 接続確認、拡張機能をオフ、別ネットワークで再実行 |
| オフラインです | 未接続 | 接続回復後に再実行（デモは可） |
| ファイルが大きすぎます | 200MB超 | 分割、またはMP3化 |
| 空のファイル／音声として認識できません／動画ファイルです | 0バイト、音声以外、動画 | 対応形式の音声を選び直す。動画は音声だけ書き出す |
| 形式未対応・破損の可能性／HTTP 400 | Geminiが読めない形式、破損 | MP3またはWAVに変換 |
| ファイルの処理に失敗しました（Files API） | 形式未対応・破損 | MP3またはWAVに変換 |
| 安全性フィルタによりブロック | 内容が安全基準に抵触と判定 | 区間を分けて再実行 |
| 出力が長すぎて途中で打ち切り | 出力上限超過 | 10〜20分程度に分割 |
| 保存できませんでした／履歴に保存されていません | ブラウザの保存容量不足・プライベートモード | 不要な履歴を削除。**結果はその場でTXT/MDに保存**（結果自体は失われません） |
| 保存できない環境です | localStorage 無効 | そのタブの間だけメモリで動作。大切な結果はTXT/MDで保存 |
| 予期しないエラーが発生しました | 想定外の例外 | ページを再読み込みして再試行 |

## 6. セキュリティ設計

- **APIキー**：ブラウザの localStorage にのみ保存。コードへの埋め込みなし。URLに載せず `x-goog-api-key` ヘッダでのみ Google API に送信。履歴・Cookie・sessionStorage・エクスポートには含まれません。入力欄は `type=password`、設定画面を離れるとDOMからも消去。「APIキーだけ削除」「すべて削除」あり。**ただし localStorage は同一オリジンの任意のスクリプトから読めるため、共用PCでは保存しないでください。** 可能であれば Google 側でキーにリファラ/API制限を設定してください。
- **XSS対策**：画面描画は全て `createElement` + `textContent` 系（`innerHTML`・`insertAdjacentHTML`・`eval`・`document.write` は不使用）。モデル応答・ファイル名・辞書・話者名・履歴など外部由来の文字列は全て文字として描画。Markdown 出力は `<` `>` をエスケープ。
- **CSP（`<meta>`）**：`default-src 'none'; script-src 'self'; style-src 'self'; connect-src 'self' https://generativelanguage.googleapis.com` ほか。`unsafe-inline`/`unsafe-eval` なし。インラインスクリプト・外部への通信は遮断され、通信先は自ドメインと Google API のみ。
- **入力の堅牢化**：履歴データは読み込み時に検証・補正（壊れたデータでも起動・表示可）。モデル応答は構造を検証（話者IDは A–Z に正規化）。
- **サーバーヘッダ（推奨・未実施）**：GitHub Pages はレスポンスヘッダを設定できないため、`frame-ancestors`（クリックジャッキング対策）、`X-Content-Type-Options: nosniff`、`Referrer-Policy`、HSTS は未設定です。独自ドメインで配信する際はサーバー側で設定してください。
- **Service Worker**：同一オリジンの GET のみキャッシュ。Google API の通信は一切キャッシュしません。

## 7. 機能と仕様

| 要件 | 実装 |
|---|---|
| 音声取込＋Gemini呼び出し | `js/gemini.js`。14MB以下は `inlineData`、**14MB超〜200MBは Files API**（resumable アップロード → `state` が ACTIVE になるまでポーリング → `fileData` で参照 → 生成後に削除を試行）。進捗表示、失敗時は理由と対処を表示 |
| モデル切替／接続テスト | 既定 `gemini-3.8-flash`／代替 `gemini-3.5-flash`／カスタムID。接続テストは `models.get`（キー有効性・モデル存在・`generateContent` 対応。音声入力対応は確認不可） |
| 4部構成 | 文字起こし全文・整文・要約・決定事項とToDo（JSONスキーマ指定で取得） |
| 捏造対策 | システムプロンプトで「推測禁止・聞き取れない箇所は `【聞き取れませんでした】`・全く聞き取れなければ他項目は空」。`uncertain` を「要確認」表示。結果画面に警告（下記） |
| 音量チェック | ブラウザ内でデコードし、有音部RMS・ピーク・無音割合・クリッピングを算出。50MB超は省略 |
| 送信前マスキング／伏せ字 | [4章](#4-個人情報を守るマスキング) |
| 話者ラベル | 名前の一括変更（ToDo担当者表記にも追従）、発言ごとの付け替え、話者追加 |
| 本文の編集 | 全タブで直接編集。履歴へ自動保存（入力中は400msで間引き、画面遷移・タブ非表示時に確実に保存） |
| 履歴 | localStorage（最大200件）。全文検索・再表示・削除。保存失敗時も結果は画面に残る |
| 出力 | タブ単位／全体コピー、TXT／Markdown |
| デモモード | キー未設定または強制ON。モックデータで全フロー（Files API経路の進捗表示も） |
| 製品体裁 | ヘッダー、初回案内、使い方、料金（ダミー）、規約・プライバシー（ひな形）、PWA（manifest＋SW＋仮アイコン） |

**捏造対策の限界**：プロンプトとスキーマでの抑制は確率的な低減策で、捏造が起きないことを保証しません。UI側でも (1) 「要確認」表示、(2) 音量「問題あり」の結果に警告、(3) 音量が極小なのに聞き取れなかった箇所がゼロの場合に追加警告、を出します。本番前に、無音・雑音のみ・小声・多話者の評価音声で**捏造率を実測**してください。

**対応音声形式**：Gemini 公式ドキュメント（音声理解、2026-11-03 確認）に記載の WAV・MP3・AIFF・AAC・OGG・FLAC・MPEG・M4A・L16・Opus・ALAW・MULAW・WebM。同ページには「1プロンプトあたり最大9.5時間」「リクエスト全体20MBまで（inline）」「20MB超は Files API を使う」との記載があります。本アプリの inline 上限14MBは base64 化（約1.33倍）を考慮した値です。

## 10. 検証状況（正直な記録）

- **確認済み**：上記の自己テスト（Chromium・ヘッドレス）。
- **未確認（重要）**：
  - **実 Gemini API との疎通**（実キーでの呼び出しは行っていません）。リクエスト形式は公式REST仕様に沿って実装しましたが、実測が必要です。
  - **Files API の実通信**：特に、ブラウザから resumable アップロードのレスポンスヘッダ `X-Goog-Upload-URL` を読めるか（CORS）は実環境で要確認です。読めない場合は「アップロード先URLを取得できませんでした」と表示され、サーバー経由のアップロードが必要になります。
  - **接続テスト**の実通信（`models.get` の応答形式、キー不正の判別）。
  - **モデルID**：公式モデル一覧（ai.google.dev/gemini-api/docs/models、2026-11-01 確認）に `gemini-3.8-flash` はありましたが、`gemini-3.5-flash` は見当たりませんでした（`gemini-3.5-flash-lite`・`gemini-3.6-flash` 等はあり）。404 の場合は設定の「カスタム」でIDを変更してください。各モデルの音声入力対応は一覧上では明記されていません。
  - ブラウザ：Chromium 以外（Safari/iOS/Firefox）の挙動、PWAインストール、日本語ファイル名でのダウンロード名（ヘッドレス Chromium では `download` になる現象を確認）。
  - 音量しきい値（`js/audio.js` の `TH`）は経験則。実録音での較正が必要です。
  - 精度（文字誤り率・捏造率・話者分離）は未評価です。

## 11. 既知の制限
- 音声サイズ上限は200MB（本アプリの設定値）。1リクエストで送るため、不安定な回線では失敗しやすい（再開・分割アップロードは未実装）。送信前マスキングは30MB以下、音量解析は50MB以下の音声のみ。
- 送信前マスキングは時間区間の手動指定のみ（自動検出なし）。マスク時は16kHzモノラルに再エンコードされる。
- 話者分離はモデル出力に依存。誤りは手動で修正。
- 編集履歴（元のAI出力との差分・元に戻す）は未対応。編集は上書き保存。
- 履歴は端末ローカル（localStorage 上限は通常5MB前後）。同期・バックアップなし。
- APIキーは localStorage に平文保存（同一オリジンのXSSや共用PCではリスク）。
- ヘルプ・規約はすべて日本語のみ。
