利用規約（試作版・案）

この規約は試作版のための案です。本格的な提供の前に、法務担当者または弁護士による確認を受けてください。制定日・運営者名は未定です。

第1条（適用）

この規約は、「議事録・文書作成支援（試作）」（以下「本アプリ」）の利用に関する条件を定めます。本アプリを利用した時点で、この規約に同意したものとみなします。

第2条（本アプリの内容）

本アプリは、利用者が入力した会議の書き起こしテキストを、議事録または復命書の様式に整えて表示する支援ツールです。整文には、利用者ご自身が取得した Google の Gemini API のキーを使用します。デモモードでは、API を使わず、架空のサンプルを表示します。

第3条（利用者の責任）

  1. 出力の内容（日時、氏名、数値、決定事項、期限など）が原文と一致しているかは、利用者が確認してください。
  2. 個人情報、機密情報、非公開情報を入力する場合は、所属する組織の情報セキュリティ規程、個人情報保護に関する定め、および Google の Gemini API の利用条件に適合していることを、利用者の責任で確認してください。
  3. APIキーの管理（取得、保存、削除、漏えい時の失効）は、利用者の責任で行ってください。共有パソコンでは、使用後に必ずキーを削除してください。
  4. Gemini API の利用に伴う料金、利用制限、およびGoogleの規約は、利用者と Google との間の関係であり、本アプリの運営者は関与しません。

第4条（禁止事項）

  • 法令または公序良俗に反する目的での利用
  • 他人の権利（著作権、プライバシーなど）を侵害する内容の入力
  • 他人のAPIキーを無断で使用すること
  • 本アプリの運営を妨げる行為

第5条（出力の正確性・免責）

生成AIの出力には、誤り、脱落、事実と異なる記述が含まれる場合があります。本アプリは、出力の正確性、完全性、特定の目的への適合性を保証しません。本アプリの利用または利用不能により生じた損害について、運営者は、故意または重過失がある場合を除き、責任を負いません。（※試作版のため、免責の範囲は法務確認が必要です。）

第6条（表記ルールについて）

本アプリの整文指示は、「公用文作成の考え方」等の一般的な公用文の考え方に基づく試作であり、特定の自治体の「文書事務の手引」等の内容と一致することを保証しません。団体の定めへの適合は、利用者が確認してください。

第7条（提供の変更・終了）

運営者は、事前の通知なく、本アプリの内容を変更し、または提供を終了することがあります。

第8条（規約の変更）

運営者は、必要に応じてこの規約を変更できます。変更後に本アプリを利用した場合は、変更後の規約に同意したものとみなします。

第9条（準拠法・管轄）

この規約は日本法に準拠します。（※管轄裁判所は、正式提供時に定めます。）
