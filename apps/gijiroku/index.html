議事録・文書作成支援 試作版

使い方 利用規約 プライバシーポリシー

会議の書き起こしテキストを貼り付けると、議事録または復命書の様式に整えて出力します。 整文には Google の Gemini API を使います（利用者ご自身の APIキーが必要）。 APIキーがなくても、デモモードで全レイアウトを確認できます。

試作版です。出力には誤りが含まれ得ます。公文書として使用する前に、必ず人が原文と照合してください。

1. 様式と入力

様式
詳細設定（氏名の伏せ字・分割処理）

氏名・固有名詞の伏せ字

2つは独立して使え、併用できます（送信前に伏せ → 結果を元に戻し → 出力は●●）。語は長いものから照合します。表記ゆれ（姓のみ、旧字体、ひらがな表記、略称など）は別の語として指定してください。指定にない語は伏せられません。「候補を抽出」は「〇〇さん」「〇〇課長」などの形だけを拾う簡易機能で、取りこぼし・誤検出があります。必ず「送信される内容を確認」で、伏せ漏れがないかを目視してください。

送信される内容の確認

長文の分割

動作確認には、サンプル文を入力して 500 程度に下げ、「デモ出力で確認」を押してください（分割→統合を模擬します）。

2. 出力

テキスト／Markdown の表示

APIキー設定（Gemini）

APIキー：未設定（デモモード）

キーはこのブラウザの localStorage にのみ保存され、運営者のサーバーには送信されません（このアプリにサーバーはありません）。 共有パソコンでは保存せず、使用後に必ず「削除」してください。キーには、利用元のサイトを制限する設定（HTTPリファラー制限）をかけることを推奨します。

モデル名は提供状況により変わります。エラーになる場合は、Google の最新のモデル一覧を確認して入力し直してください。

使い方（はじめての方へ）

所要時間の目安：デモの確認は約1分、Gemini で実際に使うまでは約5分です。

ステップ1：まず、デモで様子を見る（APIキー不要）

  1. 「様式」で「議事録」または「復命書」を選びます。
  2. 「サンプル文を入力」を押し、続けて「デモ出力で確認（APIなし）」を押します。
  3. 下に出力が表示されます。入力した文章はどこにも送信されません。

ステップ2：Gemini で実際に整文する

  1. APIキーを用意する：Google AI Studio（aistudio.google.com/apikey）で Gemini API のキーを発行します（画面の名称は変更されることがあります）。
  2. 保存する：ページ下部の「APIキー設定」にキーを貼り付けて「保存」し、続けて「接続テスト」を押します。「✓ キーの確認：有効」「✓ モデルの確認」と出れば準備完了です。
  3. 貼り付ける：書き起こしを貼り付けます（日時・場所などが分かっていれば、補助入力に書くと正確になります）。
  4. 必要なら氏名を伏せる：「詳細設定」で伏せる語を入れ、「送信前に伏せる」を有効にします。「送信される内容を確認」で、実際に送られる内容を見られます。
  5. 生成する：送信前の確認にチェックを入れ、「Gemini で整文して生成」を押します。長い文章は自動で分割され、「何件目／全何件」が表示されます。
  6. 確認・修正する：出力の「要確認事項」に、書き起こしにない情報を補った点や不明点が出ます。原文と照合し、特に日時・氏名・数値・期限を確かめてください。
  7. 取り出す：コピー、TXT／Markdown／DOCX のダウンロード、印刷（ブラウザの印刷から PDF 保存も可）が使えます。印刷では出力部分だけが印字されます。

こんなときは

「APIキーが無効です」と出る
キーを入れ直して保存し、「接続テスト」で確認します。前後の空白や全角文字が入っていないかも確かめてください。
「モデルが見つかりません（404）」と出る
「APIキー設定」のモデル名を直して保存し、「接続テスト」で「モデルの確認」が ✓ になる名前にします。
「利用上限（429）」「混み合っています」と出る
自動で最大2回まで再試行します。それでも失敗したら、少し待って「失敗した件から再開」を押します。完了済みの分は再処理されません。
長文の途中で失敗した
原因を解消して「失敗した件から再開」を押します。入力は失敗時の内容のままです（直したい場合は「生成」から最初からやり直します）。
「出力が途中で切れた」と出る
「詳細設定」の分割の目安を小さく（例：20,000字）して、最初から実行します。
「安全フィルタでブロックされた」と出る
該当しそうな部分を削除するか伏せて再実行します。様式の確認だけなら、デモモードが使えます。
DOCX のボタンが押せない
ブラウザがDOCXの生成に対応していません。TXT／Markdown でダウンロードして、Word に貼り付けてください。

整文で行うこと

  • 話し言葉・言い淀みの整理、一文を短く
  • 送り仮名（例：行う、表す）、漢字とひらがなの使い分け（例：できる、こと）
  • 数字は算用数字、日付は和暦、時刻は午前・午後を付けて表記
  • 敬語・文体の統一（常体／敬体を選べます）

表記ルールは「公用文作成の考え方」等の一般的な公用文の考え方に基づく試作です。広島市「文書事務の手引」の本文との適合は確認していません。団体の手引・例規との適合は、利用者が確認してください。
