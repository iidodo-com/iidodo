議事録・文書作成支援 試作版

使い方 利用規約 プライバシーポリシー

会議の書き起こしテキストを貼り付けると、議事録または復命書の様式に整えて出力します。 整文には Google の Gemini API を使います（利用者ご自身の APIキーが必要）。 APIキーがなくても、デモモードで全レイアウトを確認できます。

試作版です。出力には誤りが含まれ得ます。公文書として使用する前に、必ず人が原文と照合してください。

1. 様式と入力

様式
詳細設定（分割処理・氏名マスキング）

動作確認には、サンプル文を入力して 500 程度に下げ、「デモ出力で確認」を押してください（分割→統合を模擬します）。

伏字は出力にだけ適用されます。Gemini へ送信される入力テキストはマスキングされません。表記ゆれ（姓のみ、旧字体、ひらがな表記など）は別の語として指定してください。

2. 出力

テキスト／Markdown の表示

APIキー設定（Gemini）

APIキー：未設定（デモモード）

キーはこのブラウザの localStorage にのみ保存され、運営者のサーバーには送信されません（このアプリにサーバーはありません）。 共有パソコンでは保存せず、使用後に必ず「削除」してください。キーには、利用元のサイトを制限する設定（HTTPリファラー制限）をかけることを推奨します。

モデル名は提供状況により変わります。エラーになる場合は、Google の最新のモデル一覧を確認して入力し直してください。

使い方

  1. まずデモで確認：様式を選び「サンプル文を入力」→「デモ出力で確認」を押すと、APIキーなしで出力レイアウトを確認できます。
  2. APIキーを用意：Google AI Studio でキーを発行し、「APIキー設定」に入力して保存します。
  3. 貼り付けて生成：書き起こしを貼り付け、必要なら日時・場所などを補助入力し、送信前の確認にチェックして「Gemini で整文して生成」を押します。補助入力は書き起こしより優先されます。
  4. 確認・修正：「要確認事項」に、書き起こしにない情報を補った箇所や不明点が出ます。原文と照合してください。
  5. 長文：入力が分割の目安（既定60,000字）を超えると、段落単位で分割して順次処理し、結果を1つの様式に統合します。進捗は「何件目／全何件」で表示されます。統合後は、重複や取りこぼしがないか原文と照合してください。
  6. 氏名の伏字：「詳細設定」で語をカンマ区切りで指定し、チェックを入れると出力の該当語が「●●」になります。元の入力は変わりません。
  7. 接続テスト：「APIキー設定」の「接続テスト」で、キーの有効性とモデル名の存在を確認できます。
  8. 出力：コピー、TXT／Markdown／DOCX のダウンロード、印刷（ブラウザの印刷から PDF 保存も可）が使えます。印刷時は出力部分のみが印字されます。

整文で行うこと

  • 話し言葉・言い淀みの整理、一文を短く
  • 送り仮名（例：行う、表す）、漢字とひらがなの使い分け（例：できる、こと）
  • 数字は算用数字、日付は和暦、時刻は午前・午後を付けて表記
  • 敬語・文体の統一

表記ルールは「公用文作成の考え方」等の一般的な公用文の考え方に基づく試作です。広島市「文書事務の手引」の条文を取り込んだものではありません。団体の手引・例規との適合は、利用者が確認してください。
