# Text2Diagram

テキスト（会議メモ・ニュース・物語・業務フロー）から、要素と関係を抽出して
インタラクティブな図解を生成する Web アプリ。Vite + React + TypeScript + Tailwind CSS。
図は SVG 直接描画（外部の描画ライブラリ不使用）。

```bash
npm install
npm run dev      # 開発サーバ
npm run build    # 型チェック + 本番ビルド
npm test         # パーサーのユニットテスト
```

## 使い方
- 左パネルで図解タイプ（人物相関図 / 因果・対立 / 業務フロー）を選び、テキストを入力して **図解を生成**（Ctrl/⌘+Enter）。
- キャンバス: ホイールでズーム、背景ドラッグでパン、ノードドラッグで移動、ノードクリックで接続パスをハイライト（同時に編集パネルを表示）。
- 右上: 再配置 / PNG（2x）/ SVG / JSON（コピー・編集・読み込み）。

## 書式（ルールベースパーサー）
| 書き方 | 意味 |
| --- | --- |
| `A → B: 関係` / `A -> B` / `A → B → C` | 関係（チェーン可）。`<-` `←` は逆向き |
| `A -関係-> B` | ラベル付き矢印 |
| `A ⇔ B` | 双方向 |
| `A vs B: ラベル` | 対立（点線・双方向） |
| `名前(カテゴリ)` / `# 見出し` | カテゴリ指定（色分け） |
| `名前: 説明` | ノードのメモ |
| 箇条書き | 業務フローでは順に連結 |
| `AはBを〜した。` / `〜ため、〜` | 簡易な日本語文の解析 |

## AI 連携（任意）
ヘッダーの「AI設定」で OpenAI / Anthropic の API キーを設定すると、LLM が
`{ nodes, edges }` の JSON へ変換します。失敗時はルールベースに自動フォールバック。
キーは localStorage に保存され、ブラウザから各 API へ直接送信されます（共用 PC では使用しないでください）。
