# 令和８年度 事業計画概況・予算書 統合ブック 導入手順

ZIPの全ファイル（表紙・目次、01〜09の概況、02〜09の予算書、業務経理の手持資料P32〜P35）を1冊にまとめました。
決算書ブックと同じ作りで、手入力セルは黄色、Enterで次の手入力セルへ移動します。

## ファイル
| ファイル | 内容 |
|---|---|
| `R8予算書_統合版.xlsx` | 統合ブック本体（78シート）。入力ガイド・入力セル一覧・チェックを先頭に配置 |
| `mod予算書ブック.bas` | 補助マクロ（Enter移動・黄色表示ON/OFF・チェック・PDF出力・印刷・保護・カメラ図更新） |
| `mod標準報酬転記.bas` | 標準報酬資料（短期・長期）から、総括のカメラ元表へ転記するマクロ |
| `ThisWorkbook貼付用.txt` | ThisWorkbook に貼り付けるイベントコード |

## 導入（初回のみ）
1. `R8予算書_統合版.xlsx` を開き、「名前を付けて保存」で **Excelマクロ有効ブック（.xlsm）** として保存します。
2. Alt+F11 でVBEを開き、ファイル → ファイルのインポート で `mod予算書ブック.bas` と `mod標準報酬転記.bas` を取り込みます。
3. プロジェクトの「ThisWorkbook」をダブルクリックし、`ThisWorkbook貼付用.txt` の内容を貼り付けます。
4. ブックを保存して開き直します（開いたときからEnter移動が有効になります）。
5. Alt+F8 で `SetupGuideButtons` を1回実行すると、入力ガイドにボタンが並びます。

## 使い方
- 入力ガイド E9＝黄色表示（1/0）、G9＝Enterで次の手入力セルへ（1/0）。
- 手入力セルは黄色に塗ってあります。印刷・PDF出力の前にマクロが自動で消し、終わると戻します。
  - マクロを取り込む前に印刷すると、黄色のまま印刷されます。
- 手入力セルは入力セル一覧（1,836箇所）に載っています。セル番地をクリックすると移動できます。
  - H列「元の塗り（マクロ用）」は、黄色を消すときに元の色へ戻すための記録です。消さないでください。
- 概況ページの表（カメラ図）は静止画です。元表を変えたら「カメラ図の更新」（RefreshCameraPictures）を実行してください。PDF出力・印刷プレビューの前には自動で更新します。
- 業務経理は、手持資料シート（黄色欄）に入力すると予定損益のC列（令和７年度推計）・G／H列（令和８年度）へ自動連動します。
- 前年度（令和６年度）決算額は、各経理の予定損益・予定貸借のB列に手入力します。

## 注意

- 条件付き書式による黄色表示と、リンクしたカメラ図は、Excelが応答しなくなったため使っていません（塗りと静止画に変更）。
