# 令和８年度 事業計画概況・予算書 統合ブック 導入手順

ZIPの全ファイル（表紙・目次、01〜09の概況、02〜09の予算書、業務経理の手持資料P32〜P35）を1冊にまとめました。
決算書ブックと同じ作りで、手入力セルは黄色、Enterで次の手入力セルへ移動します。

## ファイル
| ファイル | 内容 |
|---|---|
| `R8予算書_統合版.xlsx` | 統合ブック本体（81シート）。入力ガイド・入力セル一覧・チェックを先頭に配置 |
| `mod予算書ブック.bas` | 補助マクロ（Enter移動・黄色表示ON/OFF・チェック・PDF出力・印刷・保護・カメラ図更新） |
| `mod環境構築後の整理.bas` | 環境構築（ボタン配置）が済んだあとに1回実行し、構築専用のマクロを削除するパッチ |
| `mod標準報酬取込.bas` | 標準報酬資料（短期・長期）の表を、入力用シート4枚へ値で取り込むマクロ（集計はシートの数式） |
| `ThisWorkbook貼付用.txt` | ThisWorkbook に貼り付けるイベントコード |

## 導入（初回のみ）
1. `R8予算書_統合版.xlsx` を開き、「名前を付けて保存」で **Excelマクロ有効ブック（.xlsm）** として保存します。
2. Alt+F11 でVBEを開き、ファイル → ファイルのインポート で `mod予算書ブック.bas` と `mod標準報酬取込.bas` を取り込みます。
3. プロジェクトの「ThisWorkbook」をダブルクリックし、`ThisWorkbook貼付用.txt` の内容を貼り付けます。
4. ブックを保存して開き直します（開いたときからEnter移動が有効になります）。
5. Alt+F8 で `SetupGuideButtons` を1回実行すると、入力ガイドにボタンが並びます。
6. 標準報酬の取込ボタンは、`SetupRemunerationButton` を1回実行すると、入力ガイドのE20に置かれます。
7. ボタンを置いたら、`mod環境構築後の整理.bas` を取り込み、`RemoveSetupOnlyCode` を1回実行します（初回のみ、「VBAプロジェクト オブジェクト モデルへのアクセスを信頼する」の設定が必要）。
   - 削除されるもの：`SetupGuideButtons`、`SetupRemunerationButton`、`ShowCommandMenu` の「ボタンを配置」の項目。
   - 配置済みのボタンは、そのまま使えます。
   - 実行後、`mod環境構築後の整理` のモジュールは、VBEで右クリック → 解放 で削除し、ブックを保存してください。

## シート名とタブの色
- **シート名**は「種別＋元ファイル番号＋経理名」です。例：`概況02短期_短－１`（02の概況・短期）、`予算07業務_予定損益`（07の予算・業務）、`入力P32業務_R08短期`（P32の手持資料。予算書ではなく入力用シート）。
  - 概況／予算の別と、ZIPのファイル番号（00〜09）で、元のファイルが分かります。
  - 表紙等・目次は00のファイルです。
- **タブの色**の意味は、入力ガイドの「5. シートタブの色の意味」と、「4. シート一覧」のタブの色の列に載せています。

| 色 | 意味 | 該当するシート |
|---|---|---|
| 黄色 | 手入力が必要（印刷する帳票・カメラ元表） | 予算書、カメラ元表、表紙等、目次 |
| 橙色 | 手入力が必要（印刷しない入力用シート） | `入力P32業務_…`（4枚） |
| 青色 | マクロで取り込む（印刷しない） | `入力標準報酬_…`（4枚） |
| 灰色 | 手入力が不要 | 数値の入力欄のない概況ページ |
| 緑色 | 管理用（印刷しない） | 入力ガイド、入力セル一覧、チェック |

- 入力欄を増減したときは、マクロ `ColorSheetTabs` で付け直せます。

## 入力用シート（予算書ではないシート）
P32〜P35の手持資料は予算書ではないため、`入力P32業務_…` の4シートとして、タブの左側（入力ガイド・入力セル一覧・チェックの次）にまとめました。印刷・PDF出力の対象外です。各シートの上部（Q1）に連携先を書いてあります。

| 入力用シート | 入力すると連携するシート |
|---|---|
| `入力P32業務_R08短期` | `予算07業務_予定損益` のG列（短期）→D列（令和８年度予算額） |
| `入力P32業務_R08長期` | `予算07業務_予定損益` のH列（長期）→D列 |
| `入力P32業務_正直短期`・`正直長期` の「R7決算見込」欄 | `予算07業務_予定損益` のC列（令和７年度推計。短期＋長期の合計） |

- 入力ガイドの「シート一覧」のH列に、シートごとの「データ連携先」を載せています。
- 取り込んでいないシート：元ブックで非表示だった「×損益説明書（市予算要求額どおり）」（どのシートからも参照されていません）と、P32の過年度シート（R07以前・再調整など35枚）。

## 標準報酬資料の取込（マクロは取り込みだけ、集計は数式）
標準報酬資料（短期・長期の標準報酬ブック）の表を、入力用シート4枚へ**値のまま**取り込みます。概況（総括）の元表は、その表のセルを指す**数式**で自動計算されます。マクロは集計をしないので、どのセルを足しているかは、数式を見れば分かります。

| 入力用シート（印刷しない） | 取り込む資料 |
|---|---|
| `入力標準報酬_短期当年度` ／ `入力標準報酬_短期翌年度` | 短期の標準報酬資料（年度の小さい方が当年度） |
| `入力標準報酬_長期当年度` ／ `入力標準報酬_長期翌年度` | 長期の標準報酬資料（同上） |

- 取り込む方法は、入力ガイドE20のボタン「標準報酬資料の取込」（マクロ `ImportStandardRemuneration`）です。資料のブックを選ぶと、全シートから標準報酬資料のシートを見つけて、年度で当年度・翌年度に振り分けます。履歴はシート「取込ログ」に残ります。資料側のエラー値（#DIV/0! など）は取り込まず、空欄にします（件数もログに残ります）。
  - 手で値貼り付け（資料のシートを全選択→コピー→入力用シートへ「値」で貼り付け）しても同じです。
- 数式の置き場所：`概況01総括_2.3ｶﾒラ`（組合員数・標準報酬、F列＝当年度、G列＝翌年度）と `概況01総括_4ｶﾒラ`（標準期末手当）。
  - 例：G5（短期組合員の人数）＝翌年度の Q16＋S16 − G8（後期高齢者等）。
  - 3月の行（16行）と年間の行（17行）を指しています。資料の行が動いたときは、数式の参照先を直してください。
  - 短期の「一般組合員」の期末手当は、AC列の「予算書用一般」を探して、その右隣（AD列）を読みます。長期は V17〜Y17 の合計です。
- 後期高齢者等（8行・40行・4ｶﾒラ20行）と被扶養者数は、資料にないため手入力のままです。
- 入力ガイドのチェックに、年度の確認（当年度＋1＝翌年度、短期と長期の当年度が同じ）を加えました。取り込む資料の年度の組み合わせが違うと、NGになります。
- ブックに入っている入力用シートの中身は、サンプルの資料（短期・長期の標準報酬ブックのR7・R8）です。実際の資料を取り込んで上書きしてください。
- 概況ページの図は、元表が変わっても自動では変わりません。取り込んだあとは、「カメラ図の更新」を実行してください。

## 使い方
- 入力ガイド E9＝黄色表示（1/0）、G9＝Enterで次の手入力セルへ（1/0）。
- 手入力セルは黄色に塗ってあります。印刷・PDF出力の前にマクロが自動で消し、終わると戻します。
  - マクロを取り込む前に印刷すると、黄色のまま印刷されます。
- 手入力セルは入力セル一覧（1,809箇所。入力用シート `入力標準報酬_…` の表は、まとめて取り込むため、セルごとの黄色にはしていません）に載っています。セル番地をクリックすると移動できます。
  - H列「元の塗り（マクロ用）」は、黄色を消すときに元の色へ戻すための記録です。消さないでください。
- 概況ページの表（カメラ図）は静止画です。元表を変えたら「カメラ図の更新」（RefreshCameraPictures）を実行してください。PDF出力・印刷プレビューの前には自動で更新します。
- 表紙等の文字と、目次のページ番号（T列）も手入力（黄色）です。ページ数が変わったら目次を直してください。
- 業務経理は、手持資料シート（黄色欄）に入力すると予定損益のC列（令和７年度推計）・G／H列（令和８年度）へ自動連動します。
- 前年度（令和６年度）決算額は、各経理の予定損益・予定貸借のB列に手入力します。

## 印刷・PDFの順序と頁番号
- 出力する順序と頁数は、原稿のPDF（94頁）と同じです。表紙→（裏の白紙）→目次2頁→概況の中扉→（裏の白紙）→概況01〜09→予算の中扉→（裏）→短期の中扉→（裏）→予算02…→貸付経理。一覧にないシートは印刷しません。
- 表紙・各中扉の裏は、原稿どおり白紙の頁を入れます（両面印刷の裏面）。
- 頁番号は、フッター中央に、目次（T列）の番号どおりに付けます。表紙・目次・中扉・裏の白紙には付けません。元のファイルにあったヘッダ・フッター（シート名、ファイル名など）は、出力時に消します。
- 番号は、頁ごとに固定の数字で書きます（Excelの自動の頁番号は、複数シートをまとめて出力すると続き方が変わるため使いません）。1頁のシートは、そのシートのフッターに書き、複数頁のシートは、改ページごとの一時コピーに分けて、それぞれに書きます。出力が終わると、一時コピーを消し、フッターを元に戻します。
- 各経理の頁数が次の経理の開始頁に足りないときは、番号付きの空白ページを経理の末尾に自動で入れます（原稿の30・38・42・46・64頁の空白）。逆に多いとき、または1頁に収まらないブロックがあるときは、確認メッセージを出します。
- 原稿の下部の番号と、出力の番号の対応は `頁番号対応表.xlsx` にあります（物理頁1〜94）。
- 番号は目次のT列（手入力）に従います。ページ構成を変えたら、T列を直してください。
- 出力が遅くならないよう、頁数を調べるのは複数頁の8シートだけにしました。出力の間は、再計算を止め、印刷設定の変更をまとめて反映します（終わると元に戻ります）。
- ExcelのPageSetup.Pages.Countで頁数を数えるため、プリンタードライバーの状態で頁数がずれることがあります。PDF出力の前に、印刷プレビューで確認してください。

## 書式と印刷の再現（原稿PDFとの突き合わせ）
- 書き出しの不具合を直して作り直しました。LibreOfficeは、書式（セルの罫線・数値のカンマ・フォントなど）の種類が約4,000を超えると、後ろのシートの書式を落とします。以前のファイルでは、予算03〜09のシートで罫線やカンマ表示が抜けていました。
  - 標準報酬の取込用シート4枚は、書式を持ち込まず、値だけの表にしました（印刷しないシートのため）。
  - 手入力セルの黄色は、書き出したあとに塗っています。
  - 日本語の文字のフォントが別の字体に置き換わる問題も直しました（MS明朝・MSゴシックなど、元のフォントのままです）。
- 列幅と図の大きさを、原稿PDFの縦横比に合わせました。1頁のシートは「1ページに収める」設定、複数頁のシートは改ページの位置はそのままで、各ブロックが1頁に収まる縮尺です。
- 頁数は、概況が各1頁、予算02：1・2・8・1・1頁、予算03：1・2・1頁、予算04〜06：各1頁×3、予算07：1・2・3・1・1頁、予算08：1・2・4・1・1頁、予算09：1・1・2・1・1頁です（原稿と同じ）。
- メモ（セルのコメント）は、印刷しない設定です。予算07の予定損益は、原稿と同じく、A〜F列だけを印刷します（G・H列は手持資料との連携用）。
- 突き合わせの結果は `原稿PDFとの突き合わせ.pdf`（左：原稿、右：出力予定）にあります。右側はLibreOfficeでの再現で、実際のExcelの出力とは数％ずれることがあります。

## 印刷の見た目（PDFとの突き合わせ）
- 目次・表紙等も、用紙の幅に収まるよう縮尺を直しました（目次75%、表紙等76%）。直す前は、目次の頁番号の列が、別のページにはみ出していました。
- 印刷・PDF出力するシートは「白黒印刷」の設定です。青・赤の文字は黒で出ます（PDFが白黒のため）。
- 印刷・PDF出力の前に、カメラ図を更新するか確認します。既定は「いいえ」で、いま貼ってある図のまま出力します。元表の数値を変えたときだけ「はい」にしてください。
- カメラ図の更新では、図の背景を白で塗り、下のセルの文字が透けて重ならないようにしました。
