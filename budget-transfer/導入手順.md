# 予算編成 自動転記 導入手順

## ファイル
| ファイル | 内容 |
|---|---|
| `07 R8予算（業務）.xlsx` | 手持資料（P32〜P35）の短期・長期シートを組み込み、○予定損益のG・H列を数式で連動。手引きシートと設定シート付き |
| `mod予算転記.bas` | 07予算ブック用マクロ（前年度決算額・当年度推計） |
| `mod概況転記.bas` | 01 R8概況（総括）用マクロ（標準報酬等） |

## 1. 07 R8予算（業務）
1. `07 R8予算（業務）.xlsx` を開き、「名前を付けて保存」で **Excelマクロ有効ブック（.xlsm）** で保存します。
2. Alt+F11 → ファイル → ファイルのインポート → `mod予算転記.bas` を選びます。
3. Alt+F8 から `転記メニュー` を実行します（1＝前年度決算額、2＝当年度推計）。
   - 実行するとブックを選ぶダイアログが開き、確認メッセージのあとに転記します。
   - 転記の履歴（旧値・新値）は「転記ログ」シートに残ります。
4. 項目1（費目ごとの予算額）はマクロ不要です。「R08業務経理 (短期)」「R08業務経理(長期)」の金額を直すと、○予定損益のG・H・D列が自動で変わります。

## 2. 01 R8概況（総括）
1. `01 R8概況（総括）.xls` を、.xlsm（または .xls のまま）でマクロを使える形で開きます。
2. Alt+F11 → ファイルのインポート → `mod概況転記.bas`。
3. Alt+F8 から `標準報酬等を転記` を実行し、Book5（当年度）とBook6（翌年度）を Ctrl を押しながら2つ選びます。

## 注意
- マクロはExcelのない環境で作成したため、実行テストは未実施です。転記ロジックは、Pythonで同じ計算を再現して既存値と照合しています。
- 初回は、念のため元ファイルをコピーしてから試してください。
