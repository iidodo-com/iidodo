# 育児時短勤務手当金：電子申請書 + 管理台帳（Excelのみ・インストール不要）

| ファイル | 使う人 | 役割 |
|---|---|---|
| `育児時短勤務手当金請求書_電子申請書.xlsx` | 職員・庶務担当 | 申請書を入力 → 入力もれ・誤りを自動チェック → 元様式どおり印刷 |
| `育児時短勤務手当金_管理台帳.xlsx` | 共済組合 | 請求を1件1行で管理。判定・決定額の自動計算、保留の管理 |

## 要望との対応
- 申請用紙の電子化／入力もれ等でエラー表示 → 電子申請書の「入力」シート（✓／✕／△を項目ごとに自動表示、最上段に総合判定。エラーが残ったまま印刷すると請求書下部に赤字警告）
- 手書きの記入もれ・誤りの確認時間 → 全角カナ、日付の実在、子の2歳到達、請求期間の自動計算、通勤手当の整合、添付書類の漏れ 等を入力時点でチェック
- 作成に時間がかかる → 請求期間・通勤手当の一括按分は自動計算。台帳は電子申請書のデータ行を貼るだけ
- 管理用Excelの改善 → 旧「短時間支給リスト」を1請求1行に整理（旧データ移行済み）。標準報酬月額・人給データから判定(○△×)・決定額を自動計算
- 保留案件の管理 → 保留理由・開始日・次回確認日を入れると「保留一覧」に自動掲載（経過日数、理由別件数）。請求前の保留は職員マスタで管理

## 前提・要確認
- 最低限度額 2,411円は旧リストの注記から設定（台帳「設定」シートで変更可）
- 請求期間の始期は「勤務開始日が月の途中ならその日」として自動計算（運用が違う場合は要相談）
- 組合員記号番号の形式は不明のため必須入力のみ確認
- Excel 2013以降。マクロ不使用。`_build/` は再生成用のPythonスクリプトで、利用には不要
