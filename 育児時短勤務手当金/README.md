# 育児時短勤務手当金：電子申請書 + 管理台帳（Excelのみ・Pythonなど不要）

| ファイル | 使う人 | 役割 |
|---|---|---|
| `育児時短勤務手当金請求書_電子申請書.xlsm` | 職員・庶務担当 | 申請書を入力 → 入力もれ・誤りを自動チェック → 印刷、または共済組合へメール送信 |
| `育児時短勤務手当金_管理台帳.xlsm` | 共済組合 | 請求を1件1行で管理。判定・決定額の自動計算、保留管理、申請書の一括取込 |

開くとき「マクロを有効にする」を押してください。各ブックの「使い方」シートにも同じ内容があります。

## ボタン
| ブック・場所 | ボタン | 動作 |
|---|---|---|
| 電子申請書「入力」上部 | 請求書を印刷 | エラーがなければ表・裏を続けて印刷。エラー時は止めて理由を表示 |
| 同上 | 共済組合へメール送信 | `fukuri@city.hiroshima.lg.jp` 宛のOutlook下書きを作成（請求書データ(Excel)とPDFを添付済み）。承認書等の写しを足して［送信］。自動送信はしません。Outlookが無ければ保存フォルダを開く |
| 同上 | 翌月分用にクリア | 対象月・報酬額・通勤手当(月額)・請求日・添付チェックだけ消す |
| 同上 | 請求日を今日に | 請求日に今日の日付を入れる |
| 管理台帳「請求記録」上部 | フォルダ内の申請書を一括取込 | メールで届いた申請書を保存したフォルダを選ぶと一括取込し、「取込済」へ移動 |
| 同上 | 申請書ファイルを取り込む | 申請書を選んで取込（複数可）。エラー残り・重複は取り込まず理由表示 |
| 同上 | 未処理に支給月を一括入力 | 基幹入力後、未処理の請求に支給月(例 R8.10)をまとめて入力 |
| 管理台帳 起動時 | （自動） | 保留中・未処理・要確認の件数を表示 |

## 給与明細シート（報酬額の自動計算）
- 電子申請書の「給与明細」シートに、支給明細書（給与の手引に基づく手当の項目を配置）の金額を転記すると、「入力」シートの「支給対象月に支払われた報酬の額」へ自動で入ります
- 総支給額から期末手当・勤勉手当・給与改定差額（と「含めない」にしたその他手当）を除き、明細に載っている通勤手当を控除して、1か月当たりの通勤手当（複数月分一括なら総額÷月数、端数は最終月）を加算します
  - 例：3か月に1回(6,300円)支給 → 支給月は6,300円を控除して2,100円を加算。支給のない月も2,100円を加算
- 控除欄・差引支給額・社会保険料計・課税対象額も明細様式どおり自動集計（報酬額の計算には使いません）
- 明細を使わず直接金額を入れる場合は、給与明細シートの「直接入力」欄（優先されます）
- メール送信用Excelには給与明細シートは含めません（支給明細書の写しを別途添付）

## 標準報酬月額
- 電子申請書の「入力」シート⑧に、標準報酬の等級・月額を入力します（請求書の☆欄に印字。決定額の目安も自動表示。決定額欄は共済組合記入のため空欄）
- 管理台帳：申請書の標準報酬月額は「共済組合提出データ」V列→請求記録に取り込まれ、職員マスタに登録が無い職員の判定に使われます。取込ボタンは、新しい職員や標準報酬月額が空の職員を職員マスタへ自動登録します。台帳の額と違う場合は「チェック」列に表示（判定は台帳の額を優先）

## 要望との対応
- 申請用紙の電子化／入力もれでエラー表示 → 入力シートの✓/✕/△表示、最上段の総合判定、エラー時の印刷・送信ブロック
- 手書きの記入もれ・誤りの確認時間 → 全角カナ、日付の実在、子の2歳到達、請求期間の自動計算、通勤手当の整合、添付書類の漏れ等を入力時点でチェック
- 作成に時間がかかる → 請求期間・通勤手当の按分は自動、翌月分はクリアして使い回し、台帳へはボタンで取込
- 管理用Excelの改善・保留管理 → 旧リストを1請求1行に整理（旧データ移行済み）、判定・決定額の自動計算、保留理由・日数の一覧管理

## 前提・要確認
- 最低限度額 2,411円は旧リストの注記から設定（台帳「設定」で変更可）
- 請求期間の始期は「勤務開始日が月の途中ならその日」として自動計算
- 組合員記号番号の形式は不明のため必須入力のみ確認
- Windows版Excel 2013以降。メール送信はOutlook必須。マクロ部分はExcel実機で未確認のため、初回はコピーで試してください
- `VBA/` はマクロのソース、`_build/` は再生成用スクリプト（利用には不要）
