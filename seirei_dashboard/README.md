# 政令指定都市 比較ダッシュボード

公的統計（総務省・e-Stat）のみを使い、政令指定都市20市を比較する単一HTML。広島市を強調表示。

## 再生成の手順

```bash
pip install openpyxl
export ESTAT_APP_ID=...        # e-Stat のアプリケーションID（国勢調査をAPIで取る場合のみ。未設定なら「未取得」表示）
python fetch_data.py           # 取得 → data/raw/（git管理外）, data/manifest.json（URL・取得日・SHA-256・更新時期）
python build_data.py           # 整形 → data/dataset.json
python build_html.py           # 生成 → out/dashboard.html
python -m unittest discover -s tests -v   # 整合性テスト
```

- 取得（fetch）／整形（build_data）／HTML生成（build_html）は独立。HTMLだけ作り直す場合は `build_html.py` のみ。
- appId は環境変数からのみ読み、保存物（manifest/dataset）には書き込まない。
- 取得できなかった値は `status: "missing"` として記録し、画面に「未取得」と表示する（補完・推測しない）。

## 使用データ（詳細は画面下部／data/manifest.json）

| 指標 | 出典 | 調査時点 |
|---|---|---|
| 職員数（部門別） | 地方公共団体定員管理調査 指定都市データ 第1表 | 令和6年4月1日 |
| 人口 | 住民基本台帳に基づく人口、人口動態及び世帯数（市区町村別・総計） | 令和6年1月1日／令和7年1月1日 |
| 人口（確定） | 令和2年国勢調査（e-Stat API 統計表ID 0003445078） | 令和2年10月1日 |
| 財政指標 | 財政状況資料集 令和5年度 総括表（市別xlsx） | 令和5年度決算 |

## 年の扱い

- 人口あたり指標の分母は **住基人口 令和6.1.1 に固定**（職員数 令和6.4.1 との差は3か月。画面に明記）。
- 住民一人あたり歳出・地方債は、令和5年度決算額を、同年度内の令和6.1.1人口で割る。
- 国勢調査（令和2年）は参考表示のみで、人口あたり指標には使わない。

## 既知の注意点

- 相模原市の国勢調査人口は、e-Stat API（725,493人）と財政状況資料集の国調欄（725,489人）で4人差。
  差異は自動検出して画面の注記に出し、テストで固定している（e-Statの値を表示）。
- 将来負担比率は、5市（相模原・浜松・大阪・堺・岡山）が資料上「－」。値なしとして順位対象外。
- 浜松市は区再編前の旧区行が秘匿値（***）のため、区合計の突合から除外。
