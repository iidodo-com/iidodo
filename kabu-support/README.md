# 株サポ

日本株の株取引サポート用スマホ PWA。テクニカル(VWAP・移動平均・RSI・出来高・信用残高)、ファンダメンタル、バックテストで選んだ戦略の売買プランを表示します。

## データ
- 株価・出来高(日足10年・5分足): Yahoo Finance chart API
- 信用残高・PER/PBR/ROE/自己資本比率・配当・業績: Yahoo!ファイナンス銘柄ページ
- 信用残高は週1回・最新週のみの公表です。履歴は更新のたびに端末へ蓄積します。

## スマホで自動更新する(推奨: パソコン不要)
ブラウザは Yahoo へ直接アクセスできないため、無料の Cloudflare Worker を1つ置きます。アプリ本体と API が1つのURLになり、設定は不要です。

1. https://dash.cloudflare.com に登録・ログイン(無料)
2. **Workers & Pages → Create → Hello World**(名前は `kabusapo` など)→ Deploy
3. **Edit code** を開き、中身を全部消して `worker/dist/kabusapo-worker.js` の内容を貼り付け → Deploy
4. 表示された `https://kabusapo.xxxx.workers.dev` をスマホで開き、ブラウザのメニューから「ホーム画面に追加」

パソコンがある場合: `node scripts/build-worker.mjs && cd worker && npx wrangler deploy`

### 更新と銘柄追加
- 画面表示中は自動更新(場中 60秒ごと、場外 10分ごと)。↻ で手動更新。アプリに戻ったときも更新します。
- 「＋」に証券コード(4桁)を入れるだけで追加(10年分の日足と財務を取得)。追加した銘柄は端末に保存され、バックテストの対象にも加わります。
- 無料枠(1日10万リクエスト)で十分動きます。URLは非公開ではないため、他人に教えないでください。

## 戦略(バックテスト)
`lib/backtest.js`。日足・現物ロング。シグナルは終値で判定し翌営業日の始値で約定、損切りは ATR ベース、往復コスト0.2%を差し引き。5戦略(押し目・高値ブレイク・ゴールデンクロス・RSI(2)逆張り・VWAP回復)×損切り幅×手仕舞い方式の51候補を検証し、**前半60%で選定・後半40%を未見データで検証**します。採用基準は事前に固定(前半: 取引40件以上・期待値>0.05R・PF≥1.3・リスクリワード≥1.5、後半: 15件以上・期待値>0・PF≥1.2・リスクリワード≥1.3)。基準を満たす中で期待値が最大のものを採用し、満たさなければ「採用なし」と表示します。登録銘柄を変えると再計算されます。

## その他
- スナップショット更新: `node scripts/fetch-data.mjs [コード...]`(Node 18+)→ `data/latest.json`
- アーティファクト用の単一HTML: `node scripts/build-artifact.mjs out.html`
- CSV取り込み(「＋」)は、API に接続していない場合の手入力用です。

## 注意
データは遅延・欠損があり得ます。判定とバックテストは参考情報で、将来の成績を保証しません。売買は自己責任です。
