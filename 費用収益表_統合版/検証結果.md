# R8 費用収益表 統合版　検証結果と引き継ぎ事項

対象ファイル: `R8_費用収益表_統合版.xlsx`（旧：業務経理区分別執行管理簿 / 貸付予算差引簿 / 費用収益表 の3ファイルを統合）

## 1. 何が変わったか

| | 旧 | 新 |
|---|---|---|
| 支払の入力 | 管理簿（業務）と予算差引簿（貸付）に入力。業務は「予算差引簿(短)(長)」にも二重入力 | **入力_業務 / 入力_貸付 の台帳1か所だけ** |
| 状態の管理 | 文字色（赤＝昨年実績／黒＝今年）と青塗り（伝票確認） | **「状態」列のプルダウン**（昨年実績／未確認／確認済／支払なし）。色は状態から自動で付く |
| 費用収益表への転記 | 月次決算時に人が転記 | **SUMIFS で自動計上**（「月次締め」で締める月を選ぶだけ） |
| 出納計算表との照合 | 目視 | **月次締めシートに入力欄と差額・判定**（費用・収益、短期／長期／貸付） |
| 数字の突合 | 目視 | **検算シート**（台帳⇔費用収益表⇔旧表）。全部 OK なら一致 |

費用収益表4枚（業務合計・短期・長期・貸付）は旧表と同じ行列配置です。台帳連動の行だけ数式になり、収益・給与・予算などは従来どおり手入力（青字）です。

## 2. 検証結果（すべて配布ファイルで実施）

| 検証 | 方法 | 結果 |
|---|---|---|
| A. 旧・費用収益表との一致 | 旧xlsの計算済み値（xlrdで読込）と、新ブックの4枚を **4,420セル**1つずつ比較（結合セル内の非表示値は除外） | **不一致 0** |
| B. 経費区分の按分 | 旧管理簿の短期／厚年／経過的／退職等（Excel計算済み値）と、新台帳の按分 **748行** を比較 | **不一致 0** |
| C. 独立再計算 | 元3ファイルから Python で別経路に再計算（四捨五入・按分・科目振り分けを別実装）し、新ブックを「9月締め」「10月締め」にして比較（438セル／511セル） | **不一致 0** |
| D. 数式エラー | 全シートの全セルを走査 | **0件** |
| 検算シート | ブック内の自動検算10項目 | **NG 0件** |

- 9月締めの状態が、旧・費用収益表（4〜9月が黒字転記済み）と完全に一致する状態です。
- 10月に切り替えると、管理簿で青塗り済みの10月分（業務37件・貸付4件）が自動計上されます（金額は業務 8,626,751円 ／ 貸付 85,874円。いずれも C. の独立再計算と一致）。
- 検証は LibreOffice 24.2 での再計算と Python で行いました。**Excel 実機では未確認**です（Excel は開くときに全再計算する設定にしてあります）。
- 再実行: `python3 費用収益表_統合版/_build/verify.py <配布ブック> <管理簿.xlsx> <貸付予算差引簿.xls> <費用収益表.xls>`

## 3. 旧ファイルで見つかった不整合（新ブックでは発生しない／要確認）

1. **管理簿「月例」M列（作業列：支給月）の誤り**（給付区分別執行額（月別）の集計に影響）
   - M36: 5/21支払の「５月分給与（短期分）248,436円」が手入力で `4`（正：5）→ 5月分が4月に集計される
   - M126: 6/30支払の「アラビック補充用 13,860円」が空欄 → 6月の月別集計から漏れる
   - M435・M436: 数式が1行下（A436・A437）を参照 → 10/29支払の「法令要覧追録 35,200円」が11月に集計される
   - 新ブックの月は常に支払日から計算するため発生しません。
2. **貸付予算差引簿の日付誤り**: 「広銀手数料（７月分）」の日付が `2025/08/31`（正：2026/08/31 と判断）。月は同じなので金額への影響はありませんが、新台帳では 2026/08/31 に直して移行しています。
3. **旧・費用収益表（貸付）10月「委託費」36,943円**が黒字（確定）だが、管理簿側は赤字（昨年実績）のまま。
4. **旧・費用収益表（業務・長期）10月「事務用消耗品費」147,320円**は黒字だが、管理簿の10月確認済は200,450円（差 53,130円。転記途中と思われます）。新ブックは9月締めでは旧表と同じ値、10月に締めると台帳の200,450円になります。
5. **青塗りがない黒字行**が、旧費用収益表では既に計上されていました（業務5件：月例10行目 60,235円／12行目 780円／13行目 520円／48行目 99,220円／261行目 550円）。旧表の数値と一致させるため「確認済」で移行しています。
6. **貸付「厚生年金保険料等」の5月 72,040円**は、管理簿の「広島県社会保険協会年会費 1,040円」と「法人市・県民税 71,000円」の合計です。科目の置き場所が適切かご確認ください（新ブックは旧表と一致させるため、現状どおり「厚生年金保険料等」に入れています。科目表の「貸付 科目」と台帳の科目で変更できます）。
7. **旧・費用収益表の手入力値（貸付「厚生年金保険料等」6月 142,650円／7月 71,325円／9月 71,325円）**は管理簿に元の行がありません。台帳に3行（摘要：「旧表の手入力値を移行」）として移しています。
8. 貸付の管理簿に日付のない赤字行が1件あります（「分担金ファックス代 6,340円」）。昨年実績のため集計には影響しません。

## 4. 移行時の判断（前提）

- 状態の移行: 赤字→昨年実績／黒字・青塗り→確認済／黒字・塗りなし→未確認。ただし旧表が既に計上済みの4〜9月の黒字は塗りの有無にかかわらず確認済。
- 管理簿「決算整理」の黒字10行（令和8年4月支払＝令和7年度分）は、令和8年度の4月（未払）には入らないため**昨年実績**で移行。
- 管理簿「月例」「決算整理」の月別合計行（790行目以降）、給付区分別執行額、端数処理は、台帳・給付区分別・科目表の数式に置き換えました。
- 費用収益表の「締め月より後」は、旧表の値（前年実績・見込）を各シート右側の非表示グループ（AA〜AM列）に保存して表示します。

## 5. 未対応・要確認

- **出納計算表は提供されていないため、照合は未検証**です（月次締めシートの黄色セルが空欄のまま）。仮締めの出納計算表の月合計を入力して差額 0 を確認してください。費用と収益の両方を比較する作りにしていますが、出納計算表の集計範囲（費用・収益のどこまでか）は私には確認できませんでした。
- **業務の「予算差引簿（短）（長）」は移行していません**（管理簿と同じ支払を二重入力していたため。外部ファイルへのリンクも含まれています）。代わりに、費用収益表の「予算残額（現在）」列と、入力_貸付の「見込残額」列で予算差引を確認できます。業務側に科目ごとの差引簿が引き続き必要でしたら、ご指示ください。
- 台帳の行数は 入力_業務 1,600行・入力_貸付 400行まであらかじめ数式が入っています（現状 748行・83行）。
- シート保護はかけていません（数式列を誤って消さないよう、必要なら保護をかけてください）。
